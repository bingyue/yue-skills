# 中国内容合规检查

## 检查维度

### 1. 广告法合规
- **极限词**："最""第一""唯一""首选""顶级""史上最低" 等
- **违禁承诺**：保证效果、保证治愈、无效退款等绝对化表述
- **价格违规**：虚假原价、全网最低等

### 2. 敏感词扫描
- 政治敏感词
- 涉及民族宗教词汇
- 暴力/色情相关词
- 平台特定禁词（微信/小红书/抖音）

### 3. 医疗健康类违规
- 食品宣传疾病治疗效果
- 保健品夸大功效
- 未经批准的医疗器械宣传
- 违反《广告法》第十六条/十七条表述

### 4. 食品类违规
- 违反 GB28050 营养声称标准
- 婴幼儿食品违规表述

## 工作流

1. 粘贴待检查文案内容
2. 指定平台（电商/微信/抖音/通用）
3. Agent 逐段扫描并标注风险位置
4. 输出风险报告：高危/中危/低危分级
5. 提供修改建议（保留原意的合规改写）

## 触发关键词

"合规检查" / "广告法审核" / "敏感词检测" / "文案风险" / "违禁词"

## 输出格式

```
合规检查报告
━━━━━━━━━━━━━━━━━━━━
风险汇总：高危 2 处 | 中危 3 处 | 低危 1 处

[高危] 第 3 段："最好的" → 建议改为 "优质的"
[中危] 第 7 段："有效治疗" → 建议删除治疗相关表述
...
```
