# 方面体系（Aspect Taxonomy）参考文档

## 使用说明

本文件定义了主要商品类目的标准方面体系。在使用 ABSA 时，优先使用此处定义的方面名称，保证输出的一致性，便于跨评论的聚合分析。

如果评论中出现了体系外的方面，可以使用 `custom_aspect: true` 标注，并在 aspect_category 中归类。

## 方面归一化规则

不同用户表达同一方面的方式各异，需要归一化到标准名称：

| 用户原文 | 归一化方面 |
|---------|---------|
| "电池撑不住" | 续航/电池 |
| "蓝牙老断" | 连接稳定性 |
| "戴久了耳朵疼" | 舒适度 |
| "快递太慢" | 物流速度 |
| "包装破损" | 物流包装 |
| "和图片不一样" | 与描述一致性 |
| "性价比高" | 价格/性价比 |
| "做工精细" | 做工/材质 |
| "颜值高" | 外观/颜值 |
| "领口扎皮肤" | 舒适度（部件：领口） |
| "尺码偏大" | 尺码/版型 |
| "洗了起球" | 耐用性 |

## 如何扩展方面体系

当现有体系中没有覆盖用户评论中出现的方面时：

1. 检查是否是现有方面的别名 → 归一化到现有方面
2. 确认出现频率 > 3% 的评论中提到 → 值得新增
3. 新增时确认所属 `aspect_category`（product_quality / service / price）
4. 在 `custom_aspect: true` 字段标注，便于后续统一更新体系

```json
{
  "aspect": "游戏延迟",
  "aspect_category": "product_quality",
  "custom_aspect": true,
  "custom_aspect_note": "该类目耳机的游戏场景评价维度，建议加入电竞类目的方面体系"
}
```
