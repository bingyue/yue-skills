# Bright Data Research Directory

## Overview

This directory contains research data and reports generated using Bright Data MCP tools for web scraping and market research. The focus is on market analysis for consumer electronics, specifically 3D printers and portable power stations. The directory is configured with Claude AI skills for automated research workflows.

## Directory Contents

### Research Reports

1. **amazon_3d_printer_research_report.md** - Comprehensive market research report on 3D printers sold on Amazon, including:
   - Market size and growth projections
   - Top-selling products analysis
   - Brand market share analysis
   - Technology trends and consumer behavior
   - Pricing strategies and profit margins
   - Competitive landscape assessment

2. **portable_power_station_data.json** - Structured data on portable power station market, including:
   - Brand positioning and product specifications
   - Capacity, output, weight, and pricing data
   - Market segmentation and trends
   - Competitive analysis of major brands (Jackery, EcoFlow, Bluetti, Anker, Goal Zero)

### Configuration Files

1. **.mcp.json** - MCP (Model Context Protocol) server configuration for:
   - Bright Data MCP server with API token
   - DuckDuckGo search MCP server

2. **.claude/settings.local.json** - Claude AI permissions configuration enabling:
   - Web search and scraping tools
   - Browser automation capabilities
   - Data extraction functions
   - File system operations

### Claude Skills

1. **research-brightdata** - Skill for comprehensive web research using Bright Data MCP tools
2. **ducksearch** - Skill for DuckDuckGo-based web searches and content extraction
