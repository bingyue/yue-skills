# 视频分镜脚本生成器 (Video Storyboard Generator)

> 融合剧情结构与画面精细描述，生成完整的视频分镜脚本，并输出AI视频生成提示词（即梦/Seedance 2.0）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 简介

这是一个为视频创作者设计的分镜脚本生成器，融合了：
- **剧情结构设计**：三幕式戏剧结构、广告式结构、宣传式结构
- **画面精细描述**：人物设定、场景环境、镜头语言、光线氛围
- **完整分镜表格**：多镜头分镜、时间分配、运镜、转场、声音设计
- **AI视频提示词**：即梦/Seedance 2.0 可用的提示词输出

## 新增：AI视频提示词生成

支持为即梦AI、Seedance 2.0等平台生成可直接使用的视频提示词：

| 特性 | 说明 |
|------|------|
| @引用系统 | 支持 `@图片作为首帧`、`@视频参考运镜` 等精准控制 |
| 时间戳分镜 | 支持0-15秒的多段落描述 |
| 运镜词库 | 21+运镜提示词，直接可用 |
| 约束词 | 稳定性控制、内容控制 |

### 平台支持

| 平台 | 模型 | 推荐 |
|------|------|------|
| 即梦AI | P2.0 Pro / S2.0 Pro | 创意短片、产品展示 |
| Seedance 2.0 | 多模态输入 | 专业视频制作 |

### 提示词结构

**基础五段式（≤12秒）**：
```
[风格/色调总纲]，[主体描述]，[动作序列]，[环境/光影]，[镜头语言]，[音效描述]
```

**时间戳分镜（13-15秒）**：
```
[时长][风格总纲]，
0-3秒：[画面 + 运镜 + 音效]；
4-8秒：[画面 + 运镜 + 音效]；
...
```

## 核心功能

### 1. 故事结构设计

| 结构类型 | 适用场景 | 特点 |
|---------|---------|------|
| 三幕式戏剧结构 | 剧情片、短片、微电影 | 建置→对抗→解决 |
| 痛点-方案-效果结构 | 广告片、带货视频 | 痛点→方案→效果→CTA |
| 吸引-展示-号召结构 | 宣传片、品牌视频 | 吸引→展示→号召 |

### 2. 画面精细描述

**人物描述**
- 基本信息：性别、年龄、体型、肤色
- 服装描述：款式、颜色、材质、细节
- 发型妆容：风格、颜色、重点
- 表情动作：情绪状态、微表情、姿态

**场景环境**
- 室内场景：家居、办公、商业空间
- 室外场景：自然、城市、特色地点
- 时间光线：清晨、正午、黄昏、夜晚

### 3. 镜头语言

**景别系统**
- 大远景 → 远景 → 全景 → 中景 → 近景 → 特写 → 大特写

**运镜方式**
- 固定、推镜头、拉镜头、摇镜头、移镜头、跟拍、环绕、升降

**转场方式**
- 硬切、叠化、淡入淡出、白场、遮罩转场

### 4. 声音设计

- 台词/旁白设计
- 音效建议
- 配乐情绪对照

## 输出内容

每次生成包含：

1. **项目信息卡片**：名称、类型、时长、平台
2. **故事结构**：幕分割、时间占比、核心任务
3. **角色的定**：外观、服装、性格、背景
4. **完整分镜表**：镜头号、时间、景别、画面描述、运镜、声音、转场
5. **剪辑节奏建议**：节奏曲线、高潮点
6. **色调变化建议**：各阶段色调、光线、后期调色
7. **配乐情绪建议**：各阶段音乐风格、乐器建议

## 使用方式

### 在 Hermes 中使用

```
# 触发词
分镜脚本、视频分镜、故事板、镜头设计、视频脚本
```

### 使用 Python 脚本

```bash
# 生成分镜脚本
python scripts/storyboard_gen.py generate "视频标题" --type 剧情 --duration 60

# 参数说明
python scripts/storyboard_gen.py generate <标题> \
  --type <类型: 剧情/广告/宣传/带货> \
  --duration <时长秒数> \
  --subject <主题描述> \
  --platform <目标平台>

# 示例：生成60秒广告分镜
python scripts/storyboard_gen.py generate "恩施藤茶广告" --type 广告 --duration 60 --platform 抖音

# 显示镜头语言参考
python scripts/storyboard_gen.py reference
```
