# 视频分镜脚本生成器

融合**剧情结构设计**与**画面精细描述**，生成完整的视频分镜脚本。

---

## 核心能力

### 1. 故事结构设计
- **三幕式结构**：建置（15%）→ 对抗（70%）→ 解决（15%）
- **开场钩子公式**：痛点刺激、悬念制造、反常识、数字冲击
- **角色弧光**：困境 → 尝试 → 改变 → 蜕变

### 2. 画面精细描述
- **人物设定**：外观、服装、发型、妆容、表情
- **场景环境**：地点、时间、环境细节
- **镜头语言**：景别、角度、运动方式
- **构图视角**：构图方式、视觉焦点
- **色彩光影**：色调、光质、光位、氛围

### 3. 分镜脚本输出
- 多镜头分镜表格
- 每个镜头的完整画面描述
- 运镜方式与时间分配
- 台词/旁白/音效
- 剪辑点与转场方式

---

## 使用流程

### Step 1：确认项目信息

**必要信息**
- 项目名称/主题
- 视频类型（短视频/广告/宣传片/剧情片）
- 视频时长

**可选信息**
- 目标平台（抖音/快手/B站/YouTube等）
- 目标人群
- 核心卖点/核心信息

### Step 2：确定故事结构

根据视频类型选择合适的结构：

| 视频类型 | 推荐结构 | 时长分配 |
|---------|---------|---------|
| 短视频/抖音 | 三幕式紧凑版 | 60-90秒 |
| 广告片 | 痛点-方案-效果 | 15-60秒 |
| 宣传片 | 吸引-展示-号召 | 30-120秒 |
| 剧情片 | 三幕式完整版 | 3-10分钟 |

### Step 3：生成分镜脚本

每个镜头包含以下维度：

#### A. 基本信息
- 镜头编号
- 时长
- 场景
- 时间点（第X秒）

#### B. 画面描述（精细）
```
【人物】
- 外观：性别、年龄、体型、肤色
- 服装：款式、颜色、材质、细节
- 发型：风格、颜色、长度
- 妆容：风格、重点
- 表情：情绪状态、微表情
- 动作：姿势、动作幅度、力度

【场景】
- 地点：具体场所
- 时间：白天/黄昏/夜晚
- 环境：建筑、自然元素、道具
- 氛围：整体感觉、情绪基调

【光线】
- 光质：硬光/柔光/漫射光
- 光位：顺光/侧光/逆光/顶光/底光
- 光比：高对比/低对比
- 色温：暖色调/冷色调/中性
```

#### C. 镜头语言
```
【景别】
- 远景：环境全貌、人物与环境关系
- 全景：人物全身、场景全貌
- 中景：膝上、腰部以上
- 近景：胸部以上
- 特写：面部、局部细节

【角度】
- 平视：正常视角
- 俯视：上帝视角、人物渺小感
- 仰视：人物高大、威严感
- 倾斜：不安、动感

【运动】
- 固定：镜头不动
- 推：镜头靠近主体
- 拉：镜头远离主体
- 摇：镜头水平转动
- 移：镜头平行移动
- 跟：跟随主体移动
- 环绕：围绕主体旋转
- 升降：镜头上下移动
```

#### D. 声音设计
- 台词/旁白
- 音效
- 背景音乐情绪

#### E. 剪辑点
- 入点：如何进入本镜头
- 出点：如何切到下一镜头
- 转场方式：硬切/叠化/淡入淡出/特殊转场

## 转场与剪辑点

### 转场方式

| 转场 | 说明 | 适用场景 |
|------|------|---------|
| 硬切 | 直接切换 | 节奏快、动作连续 |
| 叠化 | 渐变过渡 | 时间流逝、情绪变化 |
| 淡入淡出 | 黑/白场过渡 | 场景大幅跳跃、重要节点 |
| 划像 | 画面滑动 | 动感、节奏感强 |
| 匹配剪辑 | 相似元素转场 | 流畅、创意 |
| 遮罩转场 | 物体遮挡转场 | 自然过渡 |

### 剪辑点选择

```
【动作剪辑】
- 在动作进行中切换，保证流畅性

【情绪剪辑】
- 在情绪高潮点切换，强化冲击力

【节奏剪辑】
- 根据音乐节拍切换，增强节奏感

【视线剪辑】
- 先看→再看所看之物，引导观众视线
```

## 注意事项

### 画面描述原则
1. **具体可执行**：描述要让摄影师/导演能直接执行
2. **重点突出**：关键信息用更详细的描述
3. **情绪导向**：画面服务于故事和情绪
4. **视觉思维**：用视觉语言而非抽象概念

### 分镜设计原则
1. **节奏变化**：快慢结合，张弛有度
2. **景别变化**：避免连续相同景别
3. **运动流畅**：运镜要有目的性
4. **剪辑节奏**：配合音乐和情绪

### 平台适配

| 平台 | 特点 | 建议 |
|------|------|------|
| 抖音 | 竖屏、快节奏 | 3秒钩子、强节奏 |
| 快手 | 竖屏、接地气 | 真实感、情感共鸣 |
| B站 | 横屏、内容向 | 完整故事、细节丰富 |
| YouTube | 横屏、国际化 | 开场吸引、节奏适中 |

## AI视频提示词生成

本技能支持输出即梦AI、Seedance 2.0等平台的视频生成提示词。

### Seedance 2.0 @引用系统

生成提示词时支持 @引用系统，实现精准素材控制：

```
@图片1 作为首帧          # 图片作为视频第一帧
@图片2 参考风格          # 参考图片的风格/色调
@视频1 参考镜头语言       # 参考视频的运镜方式
@视频2 参考动作          # 参考人物动作
@音频1 用于配乐          # 音频作为背景音乐
@视频1 延长5s           # 将视频延长5秒
```

### 提示词结构

#### 基础五段式（≤12秒）

```
[风格/色调总纲]，[主体描述]，[动作序列]，[环境/光影]，[镜头语言]，[音效描述]
```

#### 时间戳分镜（13-15秒，推荐）

```
[时长][风格总纲]，
0-3秒：[画面 + 运镜 + 音效]；
4-8秒：[画面 + 运镜 + 音效]；
...
```

### 六维度强化公式

| 维度 | 描述重点 | 示例 |
|------|---------|------|
| 场景 | 地点、时间、光线、天气 | 夜晚下雨的东京街头，霓虹灯反射在湿漉漉的地面 |
| 主体 | 身份、服装、年龄、情绪 | 一名穿黑色风衣的冷峻特务，眼神充满警戒 |
| 动作 | 连续、具体的动态描述 | 他快步穿过人群，低头对着耳机低语 |
| 镜头 | 运动轨迹、焦距、角度 | 跟拍镜头由远景拉近，最后定格在脸部特写 |
| 风格 | 色调、质感、艺术流派 | 赛博朋克风格，冷色调，高对比，浅景深效果 |
| 声音 | 背景音乐、节奏、音效 | 低沉的电子重低音，随镜头推进节奏逐渐急促 |

### AI视频提示词输出模板

每个分镜脚本后，可选择性输出AI视频提示词：

```markdown
## AI视频提示词（即梦/Seedance 2.0）

### 完整提示词

[时长][风格总纲]，
0-X秒：[画面描述] + [运镜] + [音效]；
X-Y秒：[画面描述] + [运镜] + [音效]；
...

### @引用建议（如有素材）

- @产品图 作为首帧
- @参考图 参考风格
- @参考视频 参考运镜

### 约束词建议

- Maintain face consistency, no distortion
- stable picture, no background flickering
```

## 使用示例

### 示例1：好物分享视频

**输入**：恩施藤茶，20秒，抖音好物分享风格

**输出包含**：
1. 分镜脚本表格（6个镜头）
2. 每个镜头画面描述
3. 口播文案
4. **AI视频提示词**：

```
20秒产品展示风格，
0-5秒：产品包装正面朝镜头，快速推进，"黄酮45%"字样清晰可见，明亮顺光；
5-10秒：特写，茶叶倒入白色瓷盘，白霜细节清晰，手指轻捻展示，固定镜头；
10-15秒：玻璃杯中注入热水，茶叶舒展，茶汤金黄，热气升腾，缓推镜头；
15-20秒：端起茶杯，汤色金黄透亮，摇晃展示挂杯，固定镜头。
音效：注水声，轻快背景音乐。
约束：stable picture, product focus, no distortion
```

### 示例2：剧情短片

**输入**：健康生活宣传片，60秒，温暖正能量风格

**输出包含**：
1. 三幕式故事结构
2. 角色设定
3. 完整分镜表（10+镜头）
4. **AI视频时间戳提示词**：

```
60秒温暖治愈风格，
0-8秒：[建置] 远景，城市清晨，阳光洒向街道，航拍镜头缓慢下降；
8-25秒：[对抗] 中景，中年女性疲惫地坐在沙发上，侧光，固定镜头；
25-45秒：[转折] 中景，女性在公园散步，面色红润，跟拍镜头；
45-60秒：[解决] 全景，女性与家人欢笑，暖色调，缓慢后拉结束。
光影：从偏冷色调渐变至暖色调。
配乐：钢琴渐入，弦乐渐强。
约束：Maintain face consistency, natural movements
```
