# 镜头语言参考

## 景别系统

### 景别分类

| 景别 | 取景范围 | 人物占比 | 功能作用 |
|------|---------|---------|---------|
| 大远景 | 环境+极小人物 | <10% | 展示环境全貌、交代地理位置 |
| 远景 | 人物全身+环境 | 20-30% | 展示人物与环境关系、开场定位 |
| 全景 | 人物全身 | 约全身 | 展示完整动作、人物形象 |
| 中景 | 膝上/腰部以上 | 50% | 常用景别、人物交流、动作展示 |
| 近景 | 胸部以上 | 70% | 表情细节、人物互动 |
| 特写 | 面部/局部 | 填满画面 | 强调细节、情感传递 |
| 大特写 | 极局部 | 填满画面 | 强调关键信息、视觉冲击 |

### 景别选择原则

```
【情绪递进】
远景/全景 → 中景 → 近景 → 特写
情绪从冷到热、从观察到共情

【场景交代】
先远景/全景交代环境
再中景/近景聚焦人物

【关键强调】
重要信息用特写强调
高潮时刻用近景/特写
```

## 拍摄角度

### 角度分类

| 角度 | 描述 | 情绪效果 | 适用场景 |
|------|------|---------|---------|
| 平视 | 镜头与主体同一水平 | 客观、正常、亲切 | 对话、日常、客观叙事 |
| 俯视 | 镜头高于主体向下拍 | 渺小、脆弱、被控制 | 表现弱势、全景视角 |
| 仰视 | 镜头低于主体向上拍 | 高大、威严、强势 | 表现强势、崇拜感 |
| 倾斜 | 镜头倾斜拍摄 | 不安、紧张、动感 | 惊悚、动作、情绪失控 |
| 荷兰角 | 明显倾斜 | 失衡、混乱、紧张 | 情绪崩溃、危机时刻 |

### 角度组合运用

```
【权力关系】
强势方：仰拍（显高大）
弱势方：俯拍（显渺小）

【情绪变化】
平视→仰视：情绪升温、力量增强
平视→俯视：情绪降低、陷入困境
```

## 镜头运动

### 基本运动方式

| 运动方式 | 描述 | 功能作用 |
|---------|------|---------|
| 固定镜头 | 镜头完全不动 | 稳定、客观、专注 |
| 推镜头 | 镜头向主体靠近 | 强调、关注、压缩空间 |
| 拉镜头 | 镜头远离主体 | 揭示、扩展、释放 |
| 摇镜头 | 镜头水平转动 | 观察、浏览、跟随视线 |
| 俯仰摇 | 镜头上下转动 | 观察高度变化、揭示信息 |
| 移镜头 | 镜头平行移动 | 跟随、展示、流动 |
| 跟拍 | 镜头跟随主体移动 | 伴随感、代入感 |
| 环绕拍摄 | 围绕主体旋转 | 展示全方位、立体感 |
| 升降镜头 | 镜头上下移动 | 视点变化、揭示信息 |
| 手持镜头 | 摄影师手持拍摄 | 真实感、紧张感、临场感 |

### 运动速度

| 速度 | 描述 | 节奏感 |
|------|------|--------|
| 缓慢 | 极慢速运动 | 平静、诗意、沉重 |
| 正常 | 自然速度 | 客观、流畅 |
| 快速 | 高速运动 | 紧张、动感、冲击 |

### 运动选择原则

```
【叙事优先】
- 故事关键点用固定或慢速运动
- 保证观众看清楚

【情绪匹配】
- 紧张/冲突：快速运动、手持感
- 温情/平静：缓慢运动或固定

【节奏变化】
- 动静结合，张弛有度
- 避免连续相同运动方式
```

## 焦点与景深

### 景深效果

| 类型 | 描述 | 效果作用 |
|------|------|---------|
| 浅景深 | 背景虚化、主体清晰 | 突出主体、分离背景 |
| 深景深 | 前后都清晰 | 展示环境、交代关系 |
| 变焦 | 焦点变化移转 | 引导视线、揭示信息 |

### 焦点运用

```
【突出主体】
使用大光圈、浅景深，主体清晰，背景虚化

【交代环境】
使用小光圈、深景深，前后都清晰

【焦点切换】
先聚焦A，再切换到B，引导观众视线
"从桌上的文件（焦点）切换到人物严肃的表情（焦点）"
```

## 构图法则

### 基础构图

| 构图方式 | 描述 | 效果 |
|---------|------|------|
| 三分构图 | 主体放在1/3线交点 | 平衡、自然 |
| 中心构图 | 主体放在画面中心 | 突出、庄重、对称 |
| 对称构图 | 左右或上下对称 | 稳定、庄重、仪式感 |
| 框架构图 | 用前景框住主体 | 层次感、聚焦 |
| 对角线构图 | 沿对角线布置元素 | 动感、张力、冲击 |
| 引导线构图 | 用线条引导视线 | 空间延伸、视觉引导 |

### 视觉重量与留白

```
【视觉重量】
- 人物比环境重
- 亮部比暗部重
- 动比静重
- 大比小重

【留白运用】
- 说话者面朝方向留空白
- 运动/视线方向留空白
- 表现孤独/思考：大面积留白
```

## 经典镜头语言

### 好莱坞经典镜头

| 名称 | 描述 | 适用场景 |
|------|------|---------|
| 过肩镜头 | 从A肩后拍B | 人物对话、互动 |
| 主观镜头 | 人物视角的镜头 | 代入感、看到人物所见 |
| 反打镜头 | 180度内切换机位 | 对话正反打 |
| 反应镜头 | 表现反应的镜头 | 情绪变化、回应 |
| 建立镜头 | 交代环境的镜头 | 场景开场 |

### 情绪镜头组合

```
【对话场景】
建立镜头（全景）→ 过肩镜头（A说话）→ 反打过肩（B说话）→ 反应镜头

【情绪场景】
全景/中景（情绪触发）→ 推镜头（推进）→ 近景（表情）→ 特写（细节）

【动作场景】
全景（动作全貌）→ 中景（关键动作）→ 特写（细节冲击）→ 全景（结果）
```

## 视频专用运镜

### 运动镜头描述

| 运镜方式 | 描述词 |
|---------|--------|
| 缓慢推 | 缓慢推进镜头，聚焦人物表情 |
| 快速拉 | 快速后拉，揭示更广阔的空间 |
| 环绕 | 围绕主体360度环绕拍摄，展示全貌 |
| 跟随 | 镜头跟随人物移动，保持同速同向 |
| 升格拍摄 | 慢动作效果，强调关键瞬间 |
| 快速切换 | 快速切换镜头，制造紧张节奏 |

### 运动节奏

```
【快节奏】
- 镜头时长短（1-2秒）
- 运动速度快的镜头多
- 切换频率高

【慢节奏】
- 镜头时长长（5秒+）
- 固定或慢速运动为主
- 切换频率低
```
