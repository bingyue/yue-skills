## @引用系统

Seedance 2.0 的核心能力之一是 @引用系统，允许精确控制每个素材的功能：

### 引用格式

```
@图片1 作为首帧          # 图片作为视频第一帧
@图片2 参考风格          # 参考图片的风格/色调
@视频1 参考镜头语言       # 参考视频的运镜方式
@视频2 参考动作          # 参考人物动作
@音频1 用于配乐          # 音频作为背景音乐
@音频2 用于音效          # 音频作为环境音效
```

### 延长与融合

```
@视频1 延长5s           # 将视频延长5秒
@视频1和@视频2 融合      # 两段视频融合
```

## 提示词结构

### 基础五段式（≤12秒）

```
[风格/色调总纲]，[主体描述]，[动作序列]，[环境/光影]，[镜头语言]，[音效描述]
```

### 时间戳分镜（13-15秒，强烈推荐）

```
[时长][风格总纲]，
0-3秒：[画面 + 运镜 + 音效]；
4-8秒：[画面 + 运镜 + 音效]；
...
```

### 六维度强化公式

```
[场景] + [主体] + [动作] + [镜头] + [风格] + [声音]
```

| 维度 | 描述重点 | 示例 |
|------|---------|------|
| 场景 | 地点、时间、光线、天气 | 夜晚下雨的东京街头，霓虹灯反射在湿漉漉的地面 |
| 主体 | 身份、服装、年龄、情绪 | 一名穿黑色风衣的冷峻特务，眼神充满警戒 |
| 动作 | 连续、具体的动态描述 | 他快步穿过人群，低头对着耳机低语，不时回头张望 |
| 镜头 | 运动轨迹、焦距、角度 | 跟拍镜头由远景拉近，最后定格在脸部特写 |
| 风格 | 色调、质感、艺术流派 | 赛博朋克风格，冷色调，高对比，浅景深效果 |
| 声音 | 背景音乐、节奏、音效 | 低沉的电子重低音，随镜头推进节奏逐渐急促 |

## 运镜词库

### 推拉类

| 运镜 | 描述 | 情绪效果 |
|------|------|---------|
| 推镜头 | 镜头向主体靠近 | 强调、关注 |
| 缓慢推进 | 缓慢向主体推近 | 沉浸、聚焦 |
| 快速推进 | 快速推向主体 | 冲击、紧张 |
| 拉镜头 | 镜头远离主体 | 揭示、释放 |
| 缓慢后拉 | 缓慢远离主体 | 释然、全貌 |
| 急速后拉 | 快速拉远 | 惊愕、震撼 |

### 摇镜类

| 运镜 | 描述 | 适用场景 |
|------|------|---------|
| 左摇 | 镜头水平向左转 | 展示环境 |
| 右摇 | 镜头水平向右转 | 跟随视线 |
| 上摇 | 镜头向上转 | 展示高度 |
| 下摇 | 镜头向下转 | 揭示信息 |

### 跟拍类

| 运镜 | 描述 | 效果 |
|------|------|------|
| 前跟 | 镜头在主体前方跟随 | 伴随感、对话感 |
| 后跟 | 镜头在主体后方跟随 | 跟踪感、观察感 |
| 侧跟 | 镜头在侧面平行跟随 | 展示侧面动作 |

### 环绕与旋转

| 运镜 | 描述 | 效果 |
|------|------|------|
| 环绕拍摄 | 围绕主体360度旋转 | 展示全貌、立体感 |
| 半环绕 | 围绕主体180度旋转 | 视角转换 |
| 旋镜 | 镜头自身旋转 | 眩晕、失重 |

### 升降与移动

| 运镜 | 描述 | 效果 |
|------|------|------|
| 升镜头 | 镜头向上移动 | 上帝视角、升华感 |
| 降镜头 | 镜头向下移动 | 压抑、落地感 |
| 无人机航拍 | 高空俯瞰 | 宏大、全景 |
| 轨道移动 | 镜头沿轨道平移 | 流畅、电影感 |

### 固定镜头

| 运镜 | 描述 | 适用场景 |
|------|------|---------|
| 固定镜头 | 镜头完全不动 | 叙事、稳定 |
| 三脚架拍摄 | 稳定固定 | 画面不抖 |
| 手持感 | 微微晃动模拟手持 | 真实感、临场感 |

| 约束 | 用途 |
|------|------|

| `Character face stable without deformation` | 面部不变形 |

## 实战模板

### 电影感开场

```
无人机镜头，从雾气缭绕的山谷底部扫过，缓缓揭示日出时分广阔的山脉，金色光线穿透云层，在松林中投下长长的阴影，宏大的交响乐感，国家地理纪录片画质，超平滑的运镜
```

### 产品展示

```
[产品名称]置于纯白背景上，缓慢360度旋转展示，柔和的顶光打亮产品纹理细节，微距镜头极致特写，干净简约风格，商业级画质
```

### 人物叙事

```
15秒赛博朋克风格，
0-3秒：远景，东京霓虹街道，紫色和蓝色灯光倒映在湿润地面，无人机镜头缓慢下降；
4-8秒：中景，一位穿黑色风衣的女性特务快步穿过人群，侧跟拍镜头；
9-15秒：近景，她突然回头，眼神警觉地扫视后方，镜头缓慢推进至脸部特写；
音效：低沉的电子重低音，随镜头推进节奏逐渐急促
```

### 广告短片

```
恩施藤茶产品展示，
@产品图作为首帧，
镜头从产品正面缓慢推进，展现包装上的"黄酮45%"字样；
3-8秒：特写，倒入茶叶，白霜细节清晰可见；
8-15秒：玻璃杯冲泡，茶汤金黄，热气袅袅上升；
风格：明亮清新，暖色调，商业广告质感；

```
