# 企业微信私域运营

## 功能模块

### 1. 群 SOP 设计
- 新用户入群欢迎语（个性化/通用两版）
- 7 天激活 SOP（触达时间点 + 内容模板）
- 群活跃运营日历（每日话题/互动策略）
- 群规与公告模板

### 2. 朋友圈内容策划
- 人设打造：专家型/亲切型/生活型
- 朋友圈发圈节奏（频次/时间/内容比例）
- 内容模板：产品种草/客户案例/生活日常/知识干货
- 文案 + 配图描述一体生成

### 3. 用户标签与分层
- 标签体系设计（购买意向/消费层级/兴趣标签）
- 不同层级用户的差异化运营策略
- 流失用户召回方案

### 4. 关键词自动回复设计
- 常见问题 FAQ 模板库
- 售前/售后关键词触发回复
- 转人工阈值设计

### 5. SCRM 运营策略
- 添加好友破冰话术
- 首单转化流程设计
- 复购激活方案
