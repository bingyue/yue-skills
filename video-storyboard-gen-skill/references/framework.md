## 动作姿态模块

### 站立姿态

| 姿态 | 描述 |
|------|------|
| 自然站立 | 双脚自然分开，双手垂于身体两侧，姿态放松 |
| 侧身站立 | 身体微侧，重心落在一腿，姿态自然随性 |
| 靠墙站立 | 肩背轻靠墙面，一腿微曲，带点慵懒 |
| 双手抱胸 | 双手环抱胸前，身体放松或略紧张 |

### 坐姿

| 姿态 | 描述 |
|------|------|
| 正坐 | 双腿并拢，背部挺直，双手自然放于膝盖 |
| 盘腿坐 | 双腿交叉盘坐，上身微微前倾或后靠 |
| 侧坐 | 臀部侧面着座，双腿并拢斜向一侧 |
| 慵懒坐 | 向后靠，腿自然伸展，姿态放松 |

### 动作描述

| 动作类型 | 描述示例 |
|---------|---------|
| 行走 | 缓步走向镜头，脚步轻盈 |
| 转身 | 慢慢转身回头看，眼神跟随动作 |
| 伸手 | 伸出手触碰对方，手指微微颤抖 |
| 拥抱 | 张开双臂拥抱对方，紧紧相依 |
| 回头 | 缓缓回头，眼神定格 |

## 提示词组装规则

### 基本规则

1. **模块顺序**：人物→场景→动作→光线→镜头→风格
2. **分隔符**：中文逗号加空格 `, `
3. **描述精度**：关键人物/场景更详细，次要元素简略
4. **情绪传递**：用画面元素传递情绪而非直接说

### 输出格式

```
[具体人物描述], 位于[具体场景环境]中, [动作姿态描述]。[光线氛围], [镜头语言], [画面质感], [整体风格]
```
