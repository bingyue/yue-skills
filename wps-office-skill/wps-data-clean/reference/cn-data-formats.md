# 中国数据格式标准

## 手机号
- 格式：11位数字，以1开头
- 号段：13x, 14x, 15x, 16x, 17x, 18x, 19x
- 标准格式：`13812345678`
- 正则：`^1[3-9]\d{9}$`

## 身份证号
- 18位：6位地区码 + 8位出生日期 + 3位顺序码 + 1位校验码
- 15位（旧版）：6位地区码 + 6位出生日期 + 3位顺序码
- 校验码计算：加权求和 mod 11 对应 1,0,X,9,8,7,6,5,4,3,2
- 正则（18位）：`^\d{17}[\dX]$`

## 统一社会信用代码
- 18位：登记管理部门(1) + 机构类别(1) + 登记管理机关行政区划(6) + 主体标识码(9) + 校验码(1)
- 正则：`^[0-9A-HJ-NP-RTUW-Y]{2}\d{6}[0-9A-HJ-NP-RTUW-Y]{10}$`

## 日期格式
| 格式 | 示例 | 常见来源 |
|------|------|---------|
| YYYY-MM-DD | 2024-03-15 | ISO标准/数据库 |
| YYYY/MM/DD | 2024/03/15 | Excel默认 |
| YYYY.MM.DD | 2024.03.15 | 日常使用 |
| YYYY年M月D日 | 2024年3月15日 | 中文正式 |
| YYYYMMDD | 20240315 | 系统导出 |
| DD/MM/YYYY | 15/03/2024 | 欧洲格式 |
| MM/DD/YYYY | 03/15/2024 | 美国格式 |

## 金额格式
- 标准：`1,234,567.89`（千位逗号分隔）
- 人民币：`¥1,234.56` 或 `CNY 1,234.56`
- 大写：`壹仟贰佰叁拾肆元伍角陆分`

## 省市区编码
- 行政区划代码：6位数字
- 前2位：省/直辖市
- 中2位：地级市
- 后2位：区/县

## 邮编
- 6位数字
- 正则：`^\d{6}$`

## 银行卡号
- 16-19位数字
- Luhn校验算法验证
