# 报告生成器

自动生成结构规范、排版精美的各类报告（.docx）。

## When to Use

- 需要撰写工作报告/工作总结
- 需要写调研报告/市场分析
- 需要可行性研究报告
- 需要项目报告/结题报告
- 用户说"帮我写一份XX报告"

## When NOT to Use

- 党政机关公文 → 使用 `wps-gongwen`
- 毕业论文 → 使用 `wps-thesis`
- PPT汇报材料 → 使用 `wps-ppt-gen`

## 支持的报告类型

```text
┌───────────────────────────────────────────┐
│        报告类型选择                        │
├───────────────────────────────────────────┤
│  [1] 📊 工作总结/汇报                     │
│  [2] 🔍 调研报告/市场分析                  │
│  [3] ✅ 可行性研究报告                     │
│  [4] 📋 项目报告（启动/进展/结题）          │
│  [5] 📈 数据分析报告                       │
│  [6] 🔧 技术方案/评估报告                  │
│  [7] 💰 财务分析/审计报告                  │
│  [8] 📝 实习报告/实践报告                  │
└───────────────────────────────────────────┘
```

## 工作流程

### Step 1: 确认报告要素

- **报告类型**：从上方菜单选择
- **主题**：报告的核心主题
- **作者/部门**：撰写人信息
- **时间范围**：报告覆盖的时间段
- **关键数据**：需要包含的数据和指标
- **是否需要封面和目录**：默认包含

### Step 2: 生成报告结构

**各类型报告标准结构：**

**工作总结/汇报：**
```text
封面
目录
一、工作概述
二、主要工作成果
  2.1 成果一（含数据）
  2.2 成果二
  2.3 成果三
三、存在的问题与不足
四、经验与教训
五、下一步工作计划
附件（数据表格、图表等）
```

**调研报告：**
```text
封面
目录
摘要
一、调研背景与目的
二、调研方法与范围
  2.1 调研对象
  2.2 调研方法（问卷/访谈/数据分析）
  2.3 样本情况
三、调研结果
  3.1 数据分析
  3.2 主要发现
四、结论与建议
  4.1 结论
  4.2 建议措施
附件（调研问卷、原始数据）
```

**可行性研究报告：**
```text
封面
目录
一、项目概述
  1.1 项目背景
  1.2 项目目标
二、市场分析
  2.1 市场需求
  2.2 竞争分析
三、技术可行性
四、经济可行性
  4.1 投资估算
  4.2 收益预测
  4.3 投资回报分析
五、风险分析
  5.1 风险识别
  5.2 风险应对
六、结论与建议
```

### Step 3: 撰写内容

**报告写作原则：**
```text
1. 数据先行：用数据支撑每个论点
2. 结构清晰：遵循总-分-总结构
3. 语言客观：避免主观臆断
4. 图表辅助：关键数据用表格/图表呈现
5. 结论明确：每章有小结，全文有总结
6. 建议具体：可操作、可量化、有时限
```

### Step 4: 生成 .docx

```bash
pip install python-docx 2>/dev/null || pip3 install python-docx 2>/dev/null
```

**排版规范：**
```text
纸张：A4
页边距：上2.54cm 下2.54cm 左3.18cm 右3.18cm
封面标题：二号黑体，居中
章标题：三号黑体
节标题：四号黑体
正文：小四号宋体，首行缩进2字符，1.5倍行距
表格：五号宋体
页眉：报告标题，小五号宋体
页码：居中，小五号
```

生成逻辑复用 `wps-docx-writer` 的 DocxWriter 类，增加封面和目录方法。

### Step 5: 交付

1. 生成 .docx 文件（含封面+目录+完整章节结构）
2. 标注需要用户补充数据的位置
3. 提示在WPS中更新目录域
4. 按需调整

## 示例

```bash
# 年度工作总结
/wps-report-writer 工作总结 2025年度技术部工作总结

# 调研报告
/wps-report-writer 调研报告 关于公司数字化转型现状的调研

# 可行性报告
/wps-report-writer 可行性报告 新零售业务拓展项目可行性分析

# 项目结题
/wps-report-writer 项目报告 XX系统开发项目结题报告
```
