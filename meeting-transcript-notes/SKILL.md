# 会议录音 → 结构化纪要

## 支持输入格式

- 音频文件路径（.m4a / .mp3 / .wav）→ 先用 Whisper 或系统工具转录
- SRT / VTT 字幕文件
- 直接粘贴会议文字记录
- 会议摘要说明

## 工作流

1. **文字获取**：若为音频，先提示用户转录（可结合 `video-jianying` 或本地 Whisper）
2. **内容理解**：识别参会人、讨论主题、时间节点
3. **信息提取**：
   - ✅ 决议事项（明确达成共识的结论）
   - 📋 待办任务（who + what + when）
   - ❓ 待定事项（尚未决策的议题）
   - 💡 重要信息点（数据、方案、背景）
4. **格式输出**：标准 Markdown 会议纪要

## 输出模板

```markdown
# 会议纪要

**时间**：[日期]  **地点/形式**：[线上/线下]
**参会人**：[姓名列表]  **记录人**：AI

## 议题摘要

## 决议事项
- [ ] ...

## 待办任务
| 任务 | 负责人 | 截止时间 |
|---|---|---|

## 待定事项

## 下次会议安排
```
