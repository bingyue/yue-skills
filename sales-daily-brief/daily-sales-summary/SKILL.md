# Skill: 每日/周销售数据汇总

## 用途

自动汇总童装电商（抖音、小红书平台）的销售数据，生成结构化日报/周报，帮助快速了解业务动态。

## 触发场景

当用户说以下任何一种时，触发此 skill：

- "帮我汇总今天/本周的销售数据"
- "生成日报/周报"
- "数据汇总一下"
- "今天卖了多少"
- "这周业绩怎么样"

---

## 执行流程

### Step 1：收集数据

询问用户提供以下数据（可以是截图、文字、表格均可）：

```
请提供以下信息（有多少提多少，没有的跳过）：

【抖音端】
- 今日/本周 GMV（成交金额）
- 订单数量
- 退款金额/退款率
- 直播场次 & 场均观看人数
- 爆款 TOP3 商品及销量

【小红书端】
- 今日/本周 GMV
- 订单数量
- 笔记互动数据（点赞/收藏/评论）
- 引流转化率

【整体】
- 库存预警商品
- 下周主推款
```

### Step 2：数据处理

收到数据后，执行以下计算：

1. **环比计算**：与昨日/上周对比，计算增减幅度（%）
2. **平台占比**：抖音 vs 小红书 GMV 占比
3. **客单价**：GMV ÷ 订单数
4. **退款率**：退款金额 ÷ GMV × 100%
5. **爆款识别**：标记销量 TOP3 及其占总 GMV 比例

### Step 3：生成报告

按以下模板输出报告：

```markdown
# 童装电商 {日期} {日报/周报}

## 📊 核心指标一览

| 指标 | 今日/本周 | 昨日/上周 | 环比 |
|------|---------|---------|------|
| 总 GMV | ¥X,XXX | ¥X,XXX | ▲/▼ X% |
| 订单数 | XXX | XXX | ▲/▼ X% |
| 客单价 | ¥XX | ¥XX | ▲/▼ X% |
| 退款率 | X% | X% | ▲/▼ |

## 🛒 平台分布

- 抖音：¥X,XXX（占比 XX%）
- 小红书：¥X,XXX（占比 XX%）

## 🔥 爆款 TOP3

1. [商品名] — 销量 XXX 件，贡献 GMV ¥X,XXX
2. [商品名] — 销量 XXX 件，贡献 GMV ¥X,XXX
3. [商品名] — 销量 XXX 件，贡献 GMV ¥X,XXX

## ⚠️ 需关注

- 库存预警：[商品名] 库存不足 XX 件
- 退款异常：[如有]

## 📌 明日/下周重点

- 主推款：[商品名]
- 建议动作：[简短 1-2 条]

---
*报告生成时间：{datetime}*
```

### Step 4：保存报告（可选）

如果用户希望保存，将报告写入：

```
D:\work buddy\reports\sales\{YYYY-MM-DD}-{daily|weekly}-report.md
```

## 自动化运行说明

此 skill 可配合 WorkBuddy Automation 每天/每周定时触发。

**推荐定时配置：**
- 日报：每天 21:00（收市后汇总）
- 周报：每周日 22:00

**Automation Prompt 示例：**
```
执行 daily-sales-summary skill，提示用户输入今日抖音和小红书销售数据，汇总后生成日报并保存到 D:\work buddy\reports\sales\ 目录。
```

---

## 注意事项

1. 数据来源以用户提供为准，不自行爬取或猜测数据
2. 若数据不完整，只计算有数据的部分，缺失项标注「暂无数据」
3. 环比分析需要前期数据，首次运行时跳过环比，记录为基准值
4. 报告内容仅供内部参考，不对外发布
