# MaxC-skills

我的 WorkBuddy 个人技能库 🚀

童装电商（抖音 / 小红书）业务场景下积累的自动化工作流 skill 集合。

## 技能列表

| 技能名 | 描述 |
|--------|------|
| [daily-sales-summary](./daily-sales-summary/SKILL.md) | 每日/周销售数据自动汇总，生成结构化日报/周报 |

## 使用方式

将对应的 skill 文件夹复制到 WorkBuddy 的 skills 目录即可使用：

**Windows:**
```
C:\Users\{用户名}\.workbuddy\skills\
```
