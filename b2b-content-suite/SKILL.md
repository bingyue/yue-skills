# B2B 内容营销套件

## 内容类型

### 1. LinkedIn 文章
- **格式**：钩子开头 + 问题描述 + 洞察/方案 + 行动呼吁
- **字数**：800-1200 字（英文）/ 600-1000 字（中文）
- **风格**：专业权威，数据支撑，有具体建议
- **触发**："写一篇 LinkedIn 文章关于 [主题]"

### 2. 白皮书结构设计
- 执行摘要（2页）
- 行业背景与痛点（3页）
- 解决方案框架（5页）
- 案例研究（3页）
- 实施路径（2页）
- 总结与下一步（1页）
- **触发**："帮我设计白皮书大纲" / "白皮书结构"

### 3. 客户成功案例（Case Study）
- 挑战/解决方案/结果 三段式结构
- 量化成果（ROI/节省时间/效率提升 %）
- 客户引言提取建议
- 触发："写客户案例" / "case study" / "成功案例"

### 4. 行业洞察报告摘要
- 从长报告提取核心数据和结论
- 重写为 Executive Summary 格式
- 适配邮件/社媒分发格式

## 工作流

1. 指定内容类型 + 目标读者（CTO/CMO/采购决策人）
2. 输入产品/服务背景、客户痛点、核心价值主张
3. 指定用途（官网/LinkedIn/邮件营销/展会材料）
4. 生成内容 → 审核 → 根据反馈调整语气和数据
