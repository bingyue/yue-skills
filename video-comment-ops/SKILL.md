# 视频评论区运营

## 核心功能

### 1. 评论智能分类
- **好评**：感谢+引导分享/关注
- **差评**：问题定位+安抚+解决方案
- **咨询**：产品/价格/使用方法问题
- **互动**：段子/话题 → 借势互动
- **垃圾/恶意**：识别刷屏/竞争对手抹黑

### 2. 回复模板生成
针对每类评论生成 3-5 条差异化回复，避免机器人感：

```
[差评回复模板]
- 共情型："真的非常抱歉给您带来了不好的体验..."
- 解决型："您的问题已经记录，我们会在24小时内..."
- 升级型："能方便私信我们吗？给您一个满意的解决方案"
```

### 3. 关键词监控策略
- 差评预警关键词（退款/质量差/假货/投诉）
- 机会词（求购/哪里买/价格多少）
- 品牌词监控配置建议

### 4. 口碑管理
- 差评处理 SOP（响应时效/升级路径）
- 将差评转为正面案例的话术
- 品牌危机初步应对模板

## 工作流

1. 粘贴评论列表（或描述评论场景）
2. Agent 分类并输出优先级
3. 生成对应回复模板（可指定品牌语气）
4. 提供评论区运营日历建议
