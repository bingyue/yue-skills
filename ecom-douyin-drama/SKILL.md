# 抖音剧情带货脚本生成器（专业版）

融合**优秀脚本创作方法论**与**影视美术设计**，生成有故事深度、有视觉张力、有情感共鸣、有转化效果的带货视频脚本。

---

## 一、优秀脚本的核心标准

> "让观众忘记这是'剧本'，而沉浸于'故事'本身。"

### 1. 故事为王

| 要素 | 定义 | 抖音适配 |
|------|------|---------|
| **开场钩子** | 前3-5秒迅速抓住观众 | 冲突开场、悬念开场、情感冲击开场 |
| **世界观清晰** | 快速交代背景 | 3秒内让观众"入局" |
| **冲突贯穿** | 故事以冲突推动 | 人物内心冲突、人际冲突、人与环境冲突 |
| **情节跌宕** | 意外、反转、危机 | 每15秒一个小钩子，结尾大反转 |

### 2. 结构设计

**经典三幕式（适配抖音）**

```
第一幕【建置】（0-15%，约10-15秒）
├─ 介绍主角、背景、核心冲突
├─ 快速让观众代入
└─ 产品问题痛点暴露

第二幕【对抗】（15-85%，约50-60秒）
├─ 主角遭遇阻碍
├─ 尝试解决失败
├─ 产品作为"转机"出现
└─ 冲突升级→高潮

第三幕【解决】（85-100%，约10-15秒）
├─ 问题解决
├─ 情感升华
└─ 软性CTA（不生硬）
```

### 3. 人物塑造

| 维度 | 要求 | 抖音适配 |
|------|------|---------|
| **角色弧光** | 主角随剧情成长 | 困境→尝试→改变→蜕变 |
| **复杂性** | 非绝对善恶 | 有弱点、有挣扎、有真实感 |
| **差异化** | 人物关系推动剧情 | 对立、互补、救赎、陪伴 |
| **共情点** | 普世情感联结 | 爱、勇气、成长、家庭、尊严 |

### 4. 语言特点

| 技巧 | 说明 | 示例 |
|------|------|------|
| **避免冗余** | 每句台词推动剧情或揭示性格 | 删除所有"废话" |
| **潜台词** | 话中有话，暗示真实心理 | "我没事"（其实在忍） |
| **身份化** | 台词符合角色身份、年龄、地域 | 方言、口语、俚语 |
| **时代感** | 融入时代词汇或文化符号 | 网络用语、流行梗 |

## 二、影视美术设计要点

### 1. 场景设计

| 要素 | 要求 | 应用场景 |
|------|------|---------|
| **时代地域** | 符合故事背景 | 家居场景、职场场景、户外场景 |
| **氛围营造** | 色彩、光影、布局传达情感 | 困境场景偏暗，转机后明亮 |
| **功能性** | 支持剧情发展和人物行动 | 产品展示需要合适的光线和角度 |

**场景氛围对照表**

| 情绪 | 场景设计 | 光线 | 色调 |
|------|---------|------|------|
| 焦虑困境 | 狭窄、杂乱、压抑 | 偏暗、冷色 | 灰、蓝、暗黄 |
| 转机希望 | 开始变化 | 侧光、暖光 | 淡黄、淡粉 |
| 喜悦成功 | 明亮、整洁、开阔 | 明亮、暖色 | 白、黄、橙 |

### 2. 人物造型

| 维度 | 设计要点 |
|------|---------|
| **服装** | 符合身份、性格、时代；困境时略憔悴，成功后精神 |
| **化妆** | 困境时略加"瑕疵"（暗沉、疲态），成功后容光焕发 |
| **发型** | 反映性格和状态 |

### 3. 道具设计

| 功能 | 说明 | 带货适配 |

| **塑造人物** | 展现角色性格 | 主角的杯子、配饰暗示品味 |
| **时代象征** | 体现背景文化 | 怀旧元素、时代符号 |

### 4. 色彩设计

| 色彩 | 象征意义 | 适用场景 |

| **白色** | 纯洁、新生、希望 | 结果、蜕变 |
| **绿色** | 健康、自然、成长 | 养生类产品 |

### 5. 光影设计

| 类型 | 效果 | 应用时机 |
|------|------|---------|
| **自然光** | 真实、温暖、明亮 | 日常、转机、成功 |
| **侧光/逆光** | 立体、神秘、复杂 | 困境、挣扎 |

## 三、剧情带货核心能力

### 1. 剧情模板库

| 类型 | 核心冲突 | 情感钩子 | 适用产品 |
|------|---------|---------|---------|
| **逆袭反转** | 从困境到逆袭 | 谁都不想被看不起 | 护肤、保健品、学习类 |
| **温情治愈** | 情感矛盾到和解 | 每个人都渴望被理解 | 礼品、母婴、家居 |
| **职场成长** | 职场困境到突破 | 想升职加薪被认可 | 办公、培训、技能 |
| **家庭关系** | 家庭矛盾到化解 | 家家有本难念的经 | 家电、家居、食品 |
| **搞笑反差** | 夸张困境到解决 | 快乐驱动购买 | 零食、日用品、小家电 |

### 2. 开场钩子公式

**公式1：痛点刺激型**
```
"体检报告出来那天，我整个人都懵了..."
"结婚三年，他看我的眼神越来越冷淡..."
"做了十年打工人，我都快怀疑人生了..."
```

**公式2：悬念制造型**
```
"邻居说我这茶像发霉，结果她现在天天问我要..."
"用了三个月，医生都问我做了什么..."
"偷偷用了一个月，老公问我怎么变了..."
```

**公式3：反常识型**
```
"我以为这辈子就这样了，直到..."
"99%的人都不知道，原来..."
"千万别再...了，这样做才是对的！"
```

**公式4：数字冲击型**
```
"血压从165到正常，我只用了这一招..."
"30天，从我到她的转变..."
"花了几万块才明白的道理..."
```

### 3. 产品植入技巧

**错误做法 ❌**
- 突然打断剧情硬塞广告
- "好，说到这里给大家推荐..."
- 产品出现时机生硬
- 台词全是卖点堆砌

**正确做法 ✅**
```
植入时机 = 困境展示完毕 + 情感共鸣达到峰值 + 用户想知道"怎么解决"

产品角色：
├─ 作为"转机"出现（不是推销，是解决问题的工具）
├─ 作为"信任背书"（由可信角色推荐）
└─ 作为"改变的关键"（主角因产品而蜕变）
```

### 4. 软性CTA话术库

| 类型 | 话术模板 |
|------|---------|
| **分享型** | "如果你也遇到同样的问题，评论区告诉我，我分享给你..." |
| **对比型** | "用了三个月才发现，原来之前的努力都白费了..." |
| **隐晦型** | "不是广告，纯分享，效果太明显了藏不住..." |
| **求助型** | "有姐妹知道怎么买吗？我帮你们问问..." |
| **故事型** | "我把老家的链接放评论区了，需要的自取..." |

## 四、脚本生成流程

### Step 1：需求确认

**必要信息**
- 产品名称、功能、核心卖点
- 目标人群

**可选信息（有默认值）**
- 剧情类型（自动匹配）
- 视频时长（默认90秒）
- 主播人设（自动匹配）
- 拍摄场景（自动匹配）

### Step 2：自动匹配

```
产品类型 → 剧情类型 → 场景设计 → 色彩基调 → 光影风格

例如：
护肤品 → 逆袭反转 → 室内（梳妆台/卧室）→ 困境暗黄→成功明亮 → 侧光→顺光
保健品 → 逆袭反转 + 家庭 → 客厅/阳台 → 困境冷色→成功暖色 → 逆光→自然光
零食食品 → 搞笑反差 → 客厅/办公室 → 明亮活泼 → 自然光为主
```

### Step 3：生成脚本

输出内容：

1. **基本信息卡片**：产品、类型、人群、卖点、情感钩子
2. **剧情大纲**：三幕式结构，每幕核心任务
3. **完整分镜脚本**：镜头、时间、画面、台词、BGM、情绪
4. **口播稿（带标注）**：停顿、语气、情绪、画面提示
5. **角色人设**：外貌、性格、背景、习惯
6. **美术设计指导**：场景、服装、道具、色彩、光影
7. **标题封面**：爆款标题公式、封面文案
8. **软性CTA**：自然植入的话术

## 七、注意事项

### 广告法合规
- 不使用绝对化用语（最好、第一、唯一）
- 不夸大功效，用"调理"、"改善"替代"治疗"
- 真实案例需有依据

### 平台规则
- 避免敏感词（治愈、根治等医疗用语）
- 口播稿不要过度承诺
- 建议评论区引导购买链接

### 拍摄建议
- 时长控制在60-120秒
- 竖屏构图，表情特写
- 背景音乐配合情绪
- 产品展示角度和时间要充足
