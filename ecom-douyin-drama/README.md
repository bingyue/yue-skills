# 抖音剧情带货脚本生成器 (Douyin Drama Commerce)

> 融合优秀脚本创作方法论与影视美术设计的专业剧情带货工具

## 简介

这是一个为 AI Agent 设计的抖音剧情带货脚本生成器，将**短剧剧情**与**带货话术**完美融合，生成有故事深度、有视觉张力、有情感共鸣、有转化效果的带货视频脚本。

## 核心特性

### 1. 专业故事结构
- **三幕式结构**：建置（15%）→ 对抗（70%）→ 解决（15%）
- **开场钩子公式**：痛点刺激、悬念制造、反常识、数字冲击
- **角色弧光设计**：困境 → 尝试 → 改变 → 蜕变

### 2. 影视美术设计
- **场景氛围**：困境冷色 → 转机淡黄 → 成功暖色
- **光影变化**：配合剧情节奏，从侧光/逆光到明亮顺光
- **色彩象征**：不同的色彩传递不同情感
- **道具设计**：产品作为核心道具融入剧情

### 3. 5大剧情模板

| 类型 | 核心冲突 | 情感钩子 | 适用产品 |
|------|---------|---------|---------|
| 逆袭反转 | 困境→逆袭 | 谁都不想被看不起 | 护肤、保健品 |
| 温情治愈 | 矛盾→和解 | 每个人都渴望被理解 | 礼品、母婴 |
| 职场成长 | 困境→突破 | 想升职加薪被认可 | 学习、培训 |
| 家庭关系 | 矛盾→化解 | 家家有本难念的经 | 家电、家居 |
| 搞笑反差 | 夸张→解决 | 快乐驱动购买 | 零食、日用品 |

### 4. 产品植入方法论

**错误做法**：
- 突然打断剧情硬塞广告
- "好，说到这里给大家推荐..."
- 台词全是卖点堆砌

**正确做法**：
```
植入时机 = 困境展示完毕 + 情感共鸣达到峰值 + 用户想知道"怎么解决"

产品角色：
├─ 作为"转机"出现（不是推销，是解决问题的工具）
├─ 作为"信任背书"（由可信角色推荐）
└─ 作为"改变的关键"（主角因产品而蜕变）
```

### 5. 软性CTA话术库

- 分享型：`"如果你也遇到同样的问题，评论区告诉我，我分享给你..."`
- 隐晦型：`"不是广告，纯分享，效果太明显了藏不住..."`
- 对比型：`"用了三个月才发现，原来之前的努力都白费了..."`
- 故事型：`"我把老家的链接放评论区了，需要的自取..."`

## 输出内容

每次生成包含以下部分：

1. **基本信息卡片**：产品、类型、人群、卖点、情感钩子
2. **三幕式结构**：每幕核心任务和时间分配
3. **完整分镜脚本**：镜头、时间、画面、台词、美术、情绪
4. **口播稿（带标注）**：停顿、语气、场景、光线提示
5. **角色人设**：外貌、性格、背景、行为习惯
6. **美术设计指导**：场景、光线、色调、服装、道具
7. **标题封面建议**：爆款标题公式、封面文案
8. **质量检查清单**：故事/人物/美术/带货四维度

## 使用方式

### 作为 Hermes Skill 使用

```
# 触发词
剧情带货、带货短剧、故事型带货、场景带货、情感带货、爆款脚本
```

### 使用生成脚本

```bash
# 生成完整脚本
python scripts/drama_commerce_gen.py script "产品名" --type 产品类型 --drama 剧情类型 --duration 90

# 生成角色人设
python scripts/drama_commerce_gen.py character 女主

# 示例
python scripts/drama_commerce_gen.py script "恩施藤茶" --type 保健品 --drama 逆袭 --duration 90
```

## 注意事项

### 广告法合规
- ❌ 不使用绝对化用语（最好、第一、唯一）
- ❌ 不夸大功效，用"调理"、"改善"替代"治疗"
- ✅ 真实案例需有依据
- ✅ 建议添加"效果因人而异"

### 平台规则
- 避免敏感词（治愈、根治等医疗用语）
- 口播稿不要过度承诺
- 建议评论区引导购买链接
