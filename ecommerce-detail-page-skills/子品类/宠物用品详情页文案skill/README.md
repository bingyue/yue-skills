## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是宠物用品特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 治疗、治愈、预防疾病、恢复功能
- 绝对安全、零应激、100%适口、必吃
- 改善口臭、改善肠胃、改善毛发到某种医学程度
- 兽医级、医院同款、专业治疗级
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写功能承诺。

### 2. 补了宠物用品专用快路径

当用户已经给出：
- 产品名和品类
- 规格与价格
- 适用猫/狗及体型或年龄段
- 至少 2 个卖点
- 材质/原料/配方/结构中的至少 1 类信息
- 核心场景或竞品/价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合宠物用品的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 适配对象与使用边界
- 材质、原料、配方、颗粒或结构特点
- 实际使用频率和典型场景
- 清洁、维护、补充、更换便利性
- 竞品、价格带与主人关注点

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 宠粮/零食
- 清洁洗护/猫砂
- 玩具/磨牙/窝垫
- 牵引/喂食/出行用品

这样可以减少“用同一套问题问所有宠物用品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`适配对象 → 材质/配方 → 宠物使用体验 → 主人便利 → 使用场景`

这比通用卖点结构更适合宠物用品，也更容易写出“对宠物友好、对主人省事”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 宠物实际使用图
- 规格和颗粒/结构图
- 材质或配方特写
- 清洁维护示意图
- 居家/外出场景图
- 喂食/携带步骤图
- 适配体型说明图
