# 食品饮料详情页文案生成器

## 母版关系

当前 skill 是“全品类详情页文案母版”的食品饮料子实现。

拆分方式如下：
1. 母版负责：通用主流程、信息完整度判断、检查点、成稿骨架、自检规则
2. 当前 skill 负责：食品饮料问题池、口味表达边界、营养与配料表述、场景化写法、竞品维度

## 品类定位

这是一个围绕“口味体验 + 原料配料 + 食用场景 + 购买理由”来写详情页的子 skill，重点处理：
1. 原料与配料亮点
2. 口味、口感与风味层次
3. 营养与负担感表达边界
4. 食用场景与人群匹配
5. 规格、包装和便利性

## 适用品类

- 零食糕点
- 冲饮饮品
- 茶饮咖啡
- 健康轻食
- 即食食品
- 粮油调味
- 礼盒食品

## 不适用场景

- 保健食品、特殊医学用途食品、药品类宣传
- 涉及治疗、减肥、降三高、改善疾病的功效型宣传
- 用户明确要短视频脚本、种草帖、直播口播，而不是详情页

## 品类核心原则

1. 先讲原料与配料，再讲味道与口感，再讲场景价值
2. “好吃”必须拆成可感知的味觉体验
3. 营养标签必须有依据，不能脑补
4. 场景感要真实，不能悬浮
5. 食品文案先建立信任，再激发食欲

## 食品饮料专用快路径

如果用户已经给出以下信息中的大部分，可直接进入“信息确认 + 大纲预览”：
1. 产品名和品类
2. 规格与价格
3. 至少 2 个明确卖点
4. 原料/配料/口味中的至少 1 类明确信息
5. 竞品或价格带
6. 食用场景或目标人群

不要命中快路径的情况：
- 只说“很好吃”“很健康”“很适合减肥”
- 配料、口味、场景都空泛
- 涉及低糖、高蛋白、控卡、代餐等信息，但没有给出依据

## 首轮响应策略

### 模式A：信息不足

优先问这 5 个问题：
1. 产品名称、具体品类、规格是什么？
2. 售价或价格带是多少？
3. 这款产品最想打的 3 个卖点是什么？
4. 主要原料、配料亮点或口味特色是什么？
5. 更适合什么人、什么时间、什么场景吃或喝？

### 模式B：信息中等

如果用户已提供部分信息，优先补这几类缺口：
1. 原料和配料亮点是否明确
2. 营养标签是否有依据
3. 口味、口感或风味层次是否具体
4. 包装规格与食用便利性
5. 竞品、价格带与适用场景

### 模式C：信息较全

直接进入：
1. 产品信息汇总
2. 营养与配料表达边界确认
3. 文案大纲预览

## 食品饮料信息池

### 基础信息
1. 产品名称
2. 细分品类
3. 规格
4. 价格
5. 品牌定位

### 原料与配料
6. 主原料是什么？
7. 配料表有哪些亮点或差异？
8. 是否有低糖、无蔗糖、低脂、高蛋白、0反式脂肪等信息？
9. 是否有产地、工艺、烘焙、萃取、发酵等可讲的点？

### 口味与口感
10. 主打口味是什么？
11. 口感如何？酥、脆、绵、糯、醇、浓、清爽、回甘？
12. 有无多层风味、留香、辣度、甜度、酸度等信息？

### 场景与人群
13. 更适合解馋、早餐、下午茶、通勤、聚会、送礼、健身还是露营？
14. 核心用户是谁？
15. 食用方式、冲泡方式、保存方式是什么？

### 竞品与依据
16. 主要竞品是谁？
17. 用户为什么会拿这些竞品比较？
18. 营养、热量、糖分、蛋白质等信息是否有包装或产品页依据？

## 分品类问题池

### 零食糕点
- 主打酥脆、绵软、爆浆、浓香还是低负担？
- 原料和烘焙/制作方式有什么亮点？
- 是独立小包装、家庭分享装还是礼盒装？
- 更适合追剧、办公室、下午茶还是送礼？

### 冲饮饮品/茶咖
- 主打醇香、清爽、回甘、顺口还是提神感？
- 冲泡方式是否方便？冷泡、热冲、即溶还是即饮？
- 糖分、奶源、咖啡因或茶底信息是否明确？
- 更适合通勤、早餐、加班还是休闲场景？

### 健康轻食/功能饮品
- 是高蛋白、轻负担、低糖还是饱腹感路线？
- 营养数据是否有依据？
- 更适合代餐、加餐、运动后还是办公室备餐？
- 不要把轻食路线写成减肥医疗承诺

### 粮油调味/即食食品
- 原料、产地、工艺、风味亮点是什么？
- 更适合家庭备餐、露营、宿舍、加班还是礼赠？
- 食用方式是否简单？加热、开盖即食、搭配方式是什么？

## 合规边界

### 禁止直接写死的内容

以下内容没有明确依据时，不能写成确定事实：
- 减肥、瘦身、控糖、降脂、治疗、养胃、助眠等保健或治疗表述
- “零负担”“绝对健康”“无糖无卡”这类绝对化营养承诺
- 某个热量、糖分、蛋白质数值
- 功能饮品对体能、情绪、睡眠的明确结果承诺
- “吃不胖”“越吃越瘦”“人人适合”

### 允许的降级写法

- “更偏向轻负担路线”
- “如果用户在意控糖或高蛋白，可优先强调已确认的营养信息”
- “更适合通勤加餐或下午茶场景”
- “在同类产品中，更强调原料与风味层次”

### 广告法与极限词约束

1. 不使用“第一、唯一、顶级、极致、完美、100%”等极限词
2. 不使用“零负担、绝对健康、全网最好喝、必瘦、无敌配方”这类广告法高风险表述
3. 不把口感或营养写成绝对保证，如“绝对不胖、一定上瘾、人人都爱喝”
4. 用户原话若带极限词，输出时必须主动降级改写

## 竞品对比维度

必须从以下维度中选择适用品类项：
- 原料与配料
- 口味与风味层次
- 营养信息
- 规格与包装
- 食用便利性
- 场景适配
- 价格带

对比原则：
1. 优先比风味定位和食用体验差异
2. 少写“比竞品更健康”这类泛化结论
3. 若无依据，不写绝对领先
4. 对比结论尽量落到“更适合什么人、什么场景”

## 卖点结构

优先使用以下 5 类卖点模块：
1. 原料亮点
2. 口味体验
3. 营养或轻负担信息
4. 包装与便利性
5. 场景化价值

推荐顺序：
`原料/配料 → 口味体验 → 营养/轻负担 → 包装规格 → 食用场景`

### 卖点示例写法

- `真实果干 + 坚果搭配。配料更直给，入口先是果香，后是坚果的酥脆层次。`
- `微甜不腻。下午三四点来一包，更适合办公室补能量。`
- `独立小包装。放进通勤包、健身包都更方便，也更容易控制单次食用量。`

## 风格要求

适合“食欲感、真实感、场景感、轻负担感”，不要写成虚假保健承诺。

避免：
- 吃了就瘦
- 零卡零负担
- 全网最健康
- 一口封神

推荐：
- 酸甜更清爽，下午茶场景更合适
- 入口酥脆，越嚼越有坚果香
- 小包装更方便带去办公室或户外
- 更适合想找一款轻负担加餐的人群

## 配图建议

每个卖点至少给一种可落地配图方向。

优先给出：
- 开袋/冲泡/倒杯场景图
- 原料与配料特写
- 营养信息图
- 包装规格图
- 食用场景图
- 口味/风味对照图
- 食用方式示意图

## 成稿补充要求

1. 不得写减肥、治疗、医学功效
2. “0糖、低脂、高蛋白”等表述必须有依据
3. 口味描述要具体，避免只写“好吃”
4. 营养与负担感表达必须收敛，不能写成结果型承诺
5. 购买理由要同时覆盖“味道、便利、场景、信任感”
6. 如果信息不足，宁可收敛表达，也不要硬写健康功效
