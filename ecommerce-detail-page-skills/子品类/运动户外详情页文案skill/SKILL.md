# 运动户外详情页文案生成器

## 母版关系

当前 skill 是“全品类详情页文案母版”的运动户外子实现。

拆分方式如下：
1. 母版负责：通用主流程、信息完整度判断、检查点、成稿骨架、自检规则
2. 当前 skill 负责：运动户外问题池、功能边界、材料与结构表达、场景写法、竞品维度

## 品类定位

这是一个围绕“材料结构 + 功能表现 + 场景适配 + 持续使用价值”来写详情页的子 skill，重点处理：
1. 材料、重量与结构亮点
2. 支撑、防滑、防泼水、透气、收纳、便携等功能点
3. 跑步、骑行、徒步、露营、健身等场景差异
4. 新手、进阶、高频用户等适配关系
5. 长时间使用下的便利性和可靠性

## 适用品类

- 运动服饰
- 运动鞋履
- 健身配件
- 骑行用品
- 徒步登山用品
- 露营装备
- 训练器材与小工具

## 不适用场景

- 专业赛事器材认证说明页
- 极限运动安全认证或高风险装备合规页
- 用户明确要短视频脚本、种草帖、直播口播，而不是详情页

## 品类核心原则

1. 先讲材料和结构，再讲功能，再讲适用场景
2. 不把普通功能写成专业认证结论
3. 不用热血口号替代真实信息
4. 运动场景、频率、强度要写具体
5. 功能和场景必须一一对应，不能空喊“专业”

## 运动户外专用快路径

如果用户已经给出以下信息中的大部分，可直接进入“信息确认 + 大纲预览”：
1. 产品名和品类
2. 规格与价格
3. 至少 2 个明确卖点
4. 材料/结构/功能中的至少 1 类明确信息
5. 运动或户外使用场景
6. 竞品或价格带

不要命中快路径的情况：
- 只说“性能很强”“特别专业”“很耐用”
- 适用场景和功能点都不明确
- 功能表达涉及防护等级、极端环境或专业认证但没有依据

## 首轮响应策略

### 模式A：信息不足

优先问这 5 个问题：
1. 产品名称、具体品类和规格是什么？
2. 售价或价格带是多少？
3. 这款产品最想打的 3 个卖点是什么？
4. 材料、结构、重量、功能点上有什么明确亮点？
5. 更适合什么场景？跑步、健身、露营、骑行、徒步、通勤还是综合训练？

### 模式B：信息中等

如果用户已提供部分信息，优先补这几类缺口：
1. 材料和结构是否明确
2. 功能点与实际场景是否对应
3. 使用人群与强度等级是否明确
4. 收纳、便携、清洁或维护方式
5. 竞品、价格带与定位差异

### 模式C：信息较全

直接进入：
1. 产品信息汇总
2. 功能与使用场景边界确认
3. 文案大纲预览

## 运动户外信息池

### 基础信息
1. 产品名称
2. 细分品类
3. 规格
4. 价格
5. 品牌定位

### 材料与结构
6. 核心材料是什么？
7. 结构亮点是什么？鞋底、支架、骨架、分仓、扣具、折叠、透气孔位？
8. 重量、尺寸、收纳体积是否明确？

### 功能与体验
9. 主打轻量、支撑、防滑、防泼水、透气、耐磨、缓震、收纳、便携中的哪几项？
10. 长时间使用时的体验是什么？更稳、更轻、更省力、更容易收纳？
11. 是否有特定维护方式或耗材要求？

### 场景与人群
12. 更适合跑步、骑行、健身、露营、徒步、登山还是综合训练？
13. 适合新手、进阶还是高频用户？
14. 更适合短途、轻量、城市、周末、长时间还是多地形场景？

### 竞品与依据
15. 主要竞品是谁？
16. 用户为什么会拿这些竞品比较？
17. 防护、耐磨、防水、专业认证等信息是否有依据？

## 分品类问题池

### 运动服饰/鞋履
- 主打轻量、透气、包裹、支撑还是百搭训练场景？
- 更适合跑步、健身房、通勤运动混搭还是户外徒步？
- 鞋底、鞋面、版型、脚感、尺码建议是否明确？

### 健身配件/训练器材
- 主打支撑、辅助训练、便携、收纳还是居家使用？
- 是新手入门、家庭健身还是高频训练？
- 使用步骤、收纳方式、维护方式是否明确？

### 骑行/徒步/露营装备
- 更适合城市短途、周末户外、长线徒步还是露营整理？
- 结构、重量、容量、折叠、挂点、防泼水等信息是否明确？
- 更强调便携、安全、稳定还是空间利用率？

## 合规边界

### 禁止直接写死的内容

以下内容没有明确依据时，不能写成确定事实：
- 专业认证、赛事级、国家队同级
- 绝对防护、全地形通用、极限环境适用
- 某个缓震、防滑、防水、防风、耐磨等级
- 明确提升运动表现、减少受伤概率、显著增强体能
- 所有人群都适合、所有场景都能用

### 允许的降级写法

- “更偏向日常训练或轻户外场景”
- “如果用户更在意便携和收纳，这个卖点可以优先展开”
- “基于已知信息，优势主要集中在材料结构和使用便利性”
- “更适合某类强度、某类地形或某类训练频率”

### 广告法与极限词约束

1. 不使用“第一、唯一、顶级、极致、完美、100%”等极限词
2. 不使用“最强性能、绝对防护、全地形无敌、永久耐磨”这类广告法高风险表述
3. 不把功能和耐用性写成保证性承诺，如“绝不打滑、永不磨损、一定提升表现”
4. 用户原话若带极限词，输出时必须主动降级改写

## 竞品对比维度

必须从以下维度中选择适用品类项：
- 材质与做工
- 功能性
- 重量与便携
- 舒适度/支撑性
- 场景适配
- 耐用性
- 价格

对比原则：
1. 优先比使用场景和功能逻辑差异
2. 少写“比竞品更专业”这类空泛结论
3. 若无实证，不写绝对防护或绝对耐用
4. 对比结论尽量落到“更适合什么强度、什么人群、什么场景”

## 卖点结构

优先使用以下 5 类卖点模块：
1. 材料与结构
2. 功能表现
3. 使用体验
4. 场景适配
5. 持续使用价值

推荐顺序：
`材料/结构 → 功能表现 → 使用体验 → 运动/户外场景 → 长期价值`

### 卖点示例写法

- `轻量结构。日常通勤和轻训练切换时，携带负担更小。`
- `分区收纳。露营整理时更省步骤，也更容易快速拿到常用物品。`
- `支撑更稳。适合高频训练人群在连续动作中保持更稳的使用体验。`

## 风格要求

适合“专业感、行动感、可信度、效率感”，少喊热血空话。

避免：
- 最强性能
- 全地形无敌
- 专业运动员都在用
- 永久耐磨

推荐：
- 更适合日常高频训练场景
- 在轻量和支撑之间做了更平衡的设计
- 对需要长期携带或重复使用的人更友好
- 更适合某类运动节奏或户外使用方式

## 配图建议

每个卖点至少给一种可落地配图方向。

优先给出：
- 实际运动/户外场景图
- 功能结构拆解图
- 材料细节图
- 尺寸/收纳/重量图
- 场景对比图
- 使用动作示意图
- 携带与展开步骤图

## 成稿补充要求

1. 未确认前不要写专业认证、防护等级、极端性能
2. 对比维度必须和真实运动场景相关
3. 购买理由优先写“更稳、更轻、更耐用、更适配场景”
4. 详情页必须同时兼顾“功能信息”和“使用场景”
5. 如果信息不足，宁可收敛表达，也不要硬写专业表现承诺
