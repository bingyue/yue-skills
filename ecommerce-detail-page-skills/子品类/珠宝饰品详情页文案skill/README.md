## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是珠宝饰品特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 绝对保值、升值、收藏级
- 顶级材质、顶级切工、拍卖级、稀缺级
- 某个贵金属含量、宝石等级、证书等级
- 永不过时、人人都适合、所有场合都能戴
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写收藏或保值承诺。

### 2. 补了珠宝饰品专用快路径

当用户已经给出：
- 产品名和品类
- 价格与规格
- 至少 2 个卖点
- 材质/工艺/设计中的至少 1 类信息
- 佩戴场景或礼赠场景
- 竞品或价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合珠宝饰品的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 材质、镀层、宝石、工艺
- 尺寸、重量、佩戴方式
- 设计灵感和风格关键词
- 礼赠场景、佩戴场景与搭配关系
- 竞品、价格带与用户关注点

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 项链/手链/手镯
- 戒指/耳饰
- 胸针/腕表饰品/配饰

这样可以减少“用同一套问题问所有珠宝饰品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`材质/工艺 → 设计表达 → 佩戴氛围 → 场景搭配 → 礼赠价值`

这比通用卖点结构更适合珠宝饰品，也更容易写出“有信息、有质感、有氛围”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 佩戴上身图
- 材质和切面特写
- 尺寸对比图
- 礼盒包装图
- 多场景搭配图
- 工艺细节图
- 佩戴方式说明图
