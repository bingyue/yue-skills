# 美妆个护详情页文案生成器

## 母版关系

当前 skill 是“全品类详情页文案母版”的美妆个护子实现。

拆分方式如下：
1. 母版负责：通用主流程、信息完整度判断、检查点、成稿骨架、自检规则
2. 当前 skill 负责：美妆个护问题池、功效表达边界、竞品维度、配图方向、质感型写法

## 品类定位

这是一个围绕“成分感 + 功效感 + 使用体验 + 安心感”来写详情页的子 skill，重点处理：
1. 成分与配方卖点
2. 功效表达与体验表达的边界
3. 肤质/发质/人群适配
4. 安全感与质感表达

## 适用品类

- 面部护肤
- 彩妆底妆
- 防晒
- 洗发护发
- 身体护理
- 香氛个护
- 口腔护理

## 不适用场景

- 医疗美容项目文案
- 药品、械字号、医疗器械宣传文案
- 用户明确要种草帖、短视频脚本、朋友圈文案，而不是详情页

## 品类核心原则

1. 先讲事实，再讲感受，再讲价值
2. 功效表达必须克制，不夸张
3. 成分信息不等于医疗承诺
4. 适用人群必须谨慎，尤其是敏感肌、孕妇、儿童
5. 竞品对比优先写定位差异，不做恶意拉踩

## 美妆个护专用快路径

如果用户已经给出以下信息中的大部分，可直接进入“信息确认 + 大纲预览”：
1. 产品名和品类
2. 价格与规格
3. 至少 2 个明确卖点
4. 成分/配方/肤感中的至少 1 类明确信息
5. 竞品或价格带
6. 目标肤质/人群/使用场景

不要命中快路径的情况：
- 只说“很好用”“很温和”“效果很好”
- 成分、功效、场景全部空泛
- 产品功效存在明显合规风险但用户未说明依据

## 首轮响应策略

### 模式A：信息不足

优先问这 5 个问题：
1. 产品名称、具体品类和规格是什么？
2. 售价或价格带是多少？
3. 这款产品最想打的 3 个卖点是什么？
4. 核心成分、肤感或使用体验有什么明确亮点？
5. 目标用户是谁，适合什么肤质/发质/使用场景？

### 模式B：信息中等

如果用户已提供部分信息，优先补这几类缺口：
1. 功效依据是否明确
2. 核心成分或配方亮点
3. 适用人群与不适用边界
4. 竞品或价格带
5. 使用场景与肤感/妆感/香感

### 模式C：信息较全

直接进入：
1. 产品信息汇总
2. 功效与成分表达边界确认
3. 文案大纲预览

## 美妆个护信息池

### 基础信息
1. 产品名称
2. 细分品类
3. 规格
4. 价格
5. 品牌定位

### 配方与成分
6. 核心成分是什么？
7. 是否有浓度、专利、配方体系或技术名词？
8. 是否有不添加、温和配方或敏感肌相关信息？

### 功效与体验
9. 主打功效是什么？保湿、修护、提亮、控油、定妆、防晒、留香、柔顺？
10. 使用体验如何？清爽、滋润、轻薄、成膜快、服帖、顺滑、留香时间？
11. 是否有前后使用场景或典型痛点？

### 人群与场景
12. 适合什么肤质/发质/人群？
13. 是通勤、夜间修护、妆前、外出补涂、旅行还是节日送礼？
14. 是否有季节性场景，如换季、夏季、秋冬？

### 竞品与依据
15. 主要竞品是谁？
16. 用户为什么会拿这些竞品比较？
17. 是否有测试、实验、备案、认证、达人反馈或用户评价依据？

## 分品类问题池

### 面部护肤
- 主打补水、修护、提亮、抗初老还是舒缓？
- 核心成分是什么？是否有明确浓度或技术体系？
- 适合什么肤质？敏感肌是否有依据可写？
- 质地如何？精华、乳液、面霜、啫喱还是油状？
- 建议在护肤流程中第几步使用？

### 彩妆底妆
- 主打遮瑕、持妆、提亮、控油还是裸妆感？
- 妆效如何？奶油肌、雾面、光泽、清透还是高遮盖？
- 适合什么肤质和妆容场景？
- 色号、持妆时间、补妆体验是否明确？

### 防晒
- 是物化结合、化学还是物理防晒？
- SPF/PA 是否明确？
- 成膜速度、搓泥、泛白、拔干情况如何？
- 更适合通勤、户外还是妆前打底？

### 洗护发
- 主打控油、修护、蓬松、柔顺还是留香？
- 适合什么发质？细软塌、受损、染烫、头皮敏感？
- 香型、泡沫、冲洗感、顺滑感如何？
- 是否有无硅油、氨基酸、植萃等明确特征？

### 身体护理/口腔护理/香氛
- 是保湿、嫩肤、清洁、清新口气还是留香体验？
- 使用后体感如何？清爽、润而不黏、留香时间、刺激感？
- 适合什么日常场景？晨间、睡前、约会、通勤、运动后？

## 合规边界

### 禁止直接写死的内容

以下内容没有明确依据时，不能写成确定事实：
- 医美级、药用级、临床级
- 修复屏障到某个医学程度
- 敏感肌、孕妇、儿童绝对可用
- 祛痘、祛斑、抗敏、消炎等易涉功效宣称
- 某个成分浓度、实验结果、测试结论
- “7天见效”“一夜回春”“根治问题”

### 广告法与极限词约束

1. 不使用“第一、唯一、顶级、极致、完美、万能、永久、100%”等极限词
2. 不使用“全网爆款第一、医美级最佳替代、绝对安全、零刺激、零过敏”这类无法充分举证的广告法高风险表述
3. 不把功效体验写成保证性承诺，如“必然祛痘、一定提亮、彻底修护”
4. 用户原话若带极限词，输出时必须主动降级改写成克制表述

### 允许的降级写法

- “配方更偏向保湿修护思路”
- “如果用户更在意清爽肤感，这个卖点可以优先展开”
- “如已确认适合敏感肌，可在文案中单独强化温和度”

## 竞品对比维度

必须从以下维度中选择适用品类项：
- 成分与配方体系
- 功效方向
- 肤感/妆感/香感/发感
- 适用人群或肤质发质
- 温和度与安全背书
- 规格与价格
- 使用便利性
- 场景匹配度

对比原则：
1. 优先比定位和体验差异
2. 少写“吊打”“碾压”
3. 若无明确实证，不写绝对领先
4. 对比结论尽量落到“更适合谁”

## 卖点结构

优先使用以下 5 类卖点模块：
1. 成分亮点
2. 功效方向
3. 使用体验
4. 适用人群
5. 场景化价值

推荐顺序：
`成分/技术 → 功效表达 → 肤感/妆感/香感 → 适用人群 → 使用场景`

### 卖点示例写法

- `神经酰胺 + 角鲨烷。配方更聚焦修护保湿，换季更适合干敏肌做日常维稳。`
- `轻薄成膜。通勤前涂完不易泛白，后续跟妆也更省心。`
- `雾面妆效。更适合偏油皮在夏季通勤场景下追求清爽持妆。`

## 风格要求

适合“质感、成分感、安心感、场景感”，不要写成夸张神药风。

避免：
- 7天逆龄
- 医美级替代
- 根治、修复一切
- 全网断货王

推荐：
- 质地轻盈，上脸更清爽
- 配方聚焦保湿修护，适合换季维稳
- 日常通勤妆容更贴肤、更省步骤
- 晚间护理阶段使用，肤感更柔润

## 配图建议

每个卖点至少给一种可落地配图方向。

优先给出：
- 包材与质地图
- 成分示意图
- 使用前后场景图
- 肤感/妆感细节图
- 规格和质地特写
- 使用步骤图
- 色号/香型/功效对照图

## 成稿补充要求

1. 功效结论必须基于用户提供或已确认信息
2. 成分不要写成医疗承诺
3. 敏感肌、孕妇、婴幼儿适用性若未确认，不得直接下结论
4. 对比时少用攻击性话术，多写差异化定位
5. 美妆详情页必须同时兼顾“事实”和“使用感”
6. 如果信息不足，宁可收敛表达，也不要硬写结果型承诺
