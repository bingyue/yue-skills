## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是美妆个护特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 医美级、药用级、临床级
- 敏感肌、孕妇、儿童绝对可用
- 祛痘、祛斑、抗敏、消炎等易涉功效宣称
- 某个成分浓度、实验结果、测试结论
- “7天见效”“一夜回春”这类结果承诺
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写承诺型文案。

### 2. 补了美妆专用快路径

当用户已经给出：
- 产品名和品类
- 价格与规格
- 至少 2 个卖点
- 成分/配方/肤感中的至少 1 类信息
- 竞品或价格带
- 目标人群或使用场景

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合美妆的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 功效依据是否明确
- 核心成分或配方亮点
- 适用人群与不适用边界
- 肤感、妆感、香感
- 竞品与价格带

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 面部护肤
- 彩妆底妆
- 防晒
- 洗护发
- 身体护理/口腔护理/香氛

这样可以减少“用同一套问题问所有美妆产品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`成分/技术 → 功效表达 → 肤感/妆感/香感 → 适用人群 → 使用场景`

这比通用卖点结构更适合美妆个护，也更容易写出“既真实又有质感”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 包材与质地图
- 成分示意图
- 使用前后场景图
- 肤感/妆感细节图
- 规格和质地特写
- 使用步骤图
- 色号/香型/功效对照图
