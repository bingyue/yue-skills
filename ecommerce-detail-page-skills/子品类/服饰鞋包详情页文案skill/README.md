## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是服饰鞋包特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 绝对显瘦、绝对显高、修饰所有身材
- 永不过时、人人百搭、所有人都适合
- 顶级面料、奢品同级、设计师联名
- 某个防水、防风、速干、支撑、缓震等级
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写身材效果承诺。

### 2. 补了服饰鞋包专用快路径

当用户已经给出：
- 产品名和品类
- 价格与尺码/规格
- 至少 2 个卖点
- 面料/版型/风格中的至少 1 类信息
- 穿搭场景
- 竞品或价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合服饰鞋包的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 面料和工艺
- 版型、剪裁、鞋楦、包型
- 舒适度与实穿体验
- 尺码建议与适穿人群
- 竞品、价格带与搭配场景

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 女装/男装/童装
- 内衣/家居服
- 鞋履
- 包袋/配饰

这样可以减少“用同一套问题问所有服饰鞋包”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`面料/工艺 → 版型效果 → 穿着体验 → 场景搭配 → 实穿价值`

这比通用卖点结构更适合服饰鞋包，也更容易写出“有风格、有信息、不悬浮”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 上身全身图
- 局部面料细节图
- 尺码参考图
- 多场景搭配图
- 颜色合集图
- 鞋底/包内结构图
- 穿着动作图
