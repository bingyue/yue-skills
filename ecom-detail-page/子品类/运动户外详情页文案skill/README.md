## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是运动户外特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 专业认证、赛事级、国家队同级
- 绝对防护、全地形通用、极限环境适用
- 某个缓震、防滑、防水、防风、耐磨等级
- 明确提升运动表现、减少受伤概率、显著增强体能
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写专业表现承诺。

### 2. 补了运动户外专用快路径

当用户已经给出：
- 产品名和品类
- 规格与价格
- 至少 2 个卖点
- 材料/结构/功能中的至少 1 类信息
- 运动或户外场景
- 竞品或价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合运动户外的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 材料和结构
- 功能点与场景是否对应
- 使用人群与强度等级
- 收纳、便携、清洁或维护方式
- 竞品、价格带与定位差异

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 运动服饰/鞋履
- 健身配件/训练器材
- 骑行/徒步/露营装备

这样可以减少“用同一套问题问所有运动户外产品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`材料/结构 → 功能表现 → 使用体验 → 运动/户外场景 → 长期价值`

这比通用卖点结构更适合运动户外，也更容易写出“专业、具体、不吹过头”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 实际运动/户外场景图
- 功能结构拆解图
- 材料细节图
- 尺寸/收纳/重量图
- 场景对比图
- 使用动作示意图
- 携带与展开步骤图
