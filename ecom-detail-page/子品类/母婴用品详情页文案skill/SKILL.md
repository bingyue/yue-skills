# 母婴用品详情页文案生成器

## 母版关系

当前 skill 是“全品类详情页文案母版”的母婴用品子实现。

拆分方式如下：
1. 母版负责：通用主流程、信息完整度判断、检查点、成稿骨架、自检规则
2. 当前 skill 负责：母婴问题池、月龄与人群边界、安全材质表达、照护场景写法、竞品维度

## 品类定位

这是一个围绕“安全感 + 照护感 + 使用便利 + 家长省心”来写详情页的子 skill，重点处理：
1. 安全材质与结构卖点
2. 适用月龄/年龄段与使用边界
3. 喂养、护理、睡眠、出行等照护场景
4. 清洁、消毒、折叠、收纳等使用便利性
5. 家长视角的安心感和省心感

## 适用品类

- 喂养用品
- 洗护清洁
- 出行用品
- 安睡用品
- 护理用品
- 玩具与早教辅助用品
- 纸品与日常消耗品
- 安全防护用品

## 不适用场景

- 药品、医疗器械、治疗护理宣传
- 发育促进、智力提升、治疗改善类高风险宣传
- 用户明确要种草帖、短视频脚本、朋友圈文案，而不是详情页

## 品类核心原则

1. 安全表达必须放在第一位
2. 月龄与适用边界必须写清楚
3. 先讲材质和结构，再讲使用便利，再讲照护场景
4. 不制造育儿焦虑，不靠恐吓促进转化
5. 任何“新生儿适用”“可入口”“无刺激”都必须有依据

## 母婴用品专用快路径

如果用户已经给出以下信息中的大部分，可直接进入“信息确认 + 大纲预览”：
1. 产品名和品类
2. 价格与规格
3. 适用月龄/年龄段
4. 至少 2 个明确卖点
5. 材质/结构/使用方式中的至少 1 类明确信息
6. 核心照护场景或竞品/价格带

不要命中快路径的情况：
- 月龄或适用人群都不明确
- 只说“很安全”“很好用”“带娃必备”
- 产品安全性高度相关，但没有材质、检测、结构依据

## 首轮响应策略

### 模式A：信息不足

优先问这 5 个问题：
1. 产品名称、具体品类和规格是什么？
2. 适合多大月龄或年龄段使用？
3. 售价或价格带是多少？
4. 这款产品最想打的 3 个卖点是什么？材质、结构或功能上有什么亮点？
5. 主要用于什么照护场景？喂养、睡眠、外出、护理还是家中防护？

### 模式B：信息中等

如果用户已提供部分信息，优先补这几类缺口：
1. 月龄/年龄段和适用边界是否明确
2. 材质、结构、安全依据是否明确
3. 使用方式和照护场景
4. 清洁、消毒、收纳、携带便利性
5. 竞品、价格带与家长关注点

### 模式C：信息较全

直接进入：
1. 产品信息汇总
2. 安全与适用边界确认
3. 文案大纲预览

## 母婴用品信息池

### 基础信息
1. 产品名称
2. 细分品类
3. 规格
4. 价格
5. 品牌定位

### 安全与材质
6. 核心材质是什么？
7. 是否有检测、认证、材质说明或工艺亮点？
8. 是否涉及食品接触、啃咬、贴肤、入口等高敏场景？

### 月龄与使用边界
9. 适合多大月龄或年龄段？
10. 是否有不适用人群或注意事项？
11. 是家长辅助使用，还是宝宝可独立使用？

### 结构与体验
12. 结构、尺寸、容量、折叠或安装方式如何？
13. 使用时的便利性是什么？快装、易洗、易收纳、便携？
14. 是否有清洁、消毒、拆洗或替换耗材要求？

### 场景与竞品
15. 是喂养、睡眠、出行、护理还是防护场景？
16. 主要竞品是谁？
17. 家长为什么会拿这些竞品来比较？

## 分品类问题池

### 喂养用品
- 奶瓶、餐具、辅食工具适合多大月龄？
- 材质是否明确？PP、PPSU、硅胶、不锈钢等是否可写？
- 是否涉及防胀气、防漏、易清洗、易握持等卖点？
- 是家用、外出还是辅食阶段使用？

### 洗护清洁
- 主打温和、洁净、便捷还是省步骤？
- 是否贴肤、入口、接触头皮或口腔？
- 香味、刺激感、清洁感、冲洗便利性是否明确？
- 是否适合特定年龄段或特定肤质？

### 出行用品
- 主要解决外出携带、折叠收纳、安抚、喂养还是便捷护理问题？
- 重量、折叠方式、收纳体积、上车/上手是否方便？
- 更适合短途、长途、日常通勤还是旅行？

### 安睡/护理/安全防护
- 主打支撑、包裹、防护、陪伴还是清洁护理？
- 尺寸、材质、安装方式是否明确？
- 更适合夜间护理、床边照护、家中防护还是宝宝活动区？

## 合规边界

### 禁止直接写死的内容

以下内容没有明确依据时，不能写成确定事实：
- 新生儿适用、全龄适用、孕妇可用
- 可入口、可啃咬、0刺激、0风险、绝对安全
- 促进发育、提升智力、改善睡眠、预防疾病、替代护理
- 医疗级、医院同款、专业级防护
- 某个检测结果、认证结论、材质等级

### 允许的降级写法

- “更偏向日常照护场景使用”
- “如果已确认适合新生儿，可在文案中强化这一点”
- “更适合家长在外出场景下提升使用便利性”
- “基于已知信息，优势集中在材质与使用便捷性”

### 广告法与极限词约束

1. 不使用“第一、唯一、顶级、极致、完美、100%”等极限词
2. 不使用“绝对安全、零风险、全龄通用、最好带娃神器”这类无法充分举证的广告法高风险表述
3. 不把安全、舒适、适龄写成保证性承诺，如“绝不呛奶、绝不刺激、一定秒睡”
4. 用户原话若带极限词，输出时必须主动降级改写

## 竞品对比维度

必须从以下维度中选择适用品类项：
- 安全材质
- 年龄段适配
- 使用便捷性
- 清洁维护
- 收纳与外出便利
- 结构设计
- 价格与规格

对比原则：
1. 优先比安全设计和使用便利差异
2. 少写“比竞品更安全”这种无依据绝对结论
3. 若无明确认证或测试，不写断言型结果
4. 对比结论尽量落到“更适合哪类家庭、哪类场景”

## 卖点结构

优先使用以下 5 类卖点模块：
1. 安全材质
2. 结构设计
3. 使用便利
4. 照护场景
5. 家长安心感

推荐顺序：
`安全材质/结构 → 使用便利 → 清洁维护 → 照护场景 → 家长价值`

### 卖点示例写法

- `食品接触材质。更适合日常喂养场景，家长使用时也更安心。`
- `一拧即开。夜间冲奶或外出补喂时，操作更省步骤。`
- `可拆洗结构。清洁环节更直接，也更适合高频使用家庭。`

## 风格要求

适合“安心、温和、照护感、秩序感”，避免焦虑营销和恐吓式文案。

避免：
- 带娃必买第一名
- 不买就会后悔
- 绝对安全
- 宝宝一用就不哭

推荐：
- 更适合日常高频照护场景
- 操作步骤更简单，家长使用更省心
- 外出携带更方便，减少临时翻找负担
- 在安全材质和清洁便利之间做了更平衡的设计

## 配图建议

每个卖点至少给一种可落地配图方向。

优先给出：
- 亲子使用场景图
- 材质/结构细节图
- 安装或使用步骤图
- 尺寸与收纳图
- 清洁消毒示意图
- 外出携带场景图
- 月龄/使用方式说明图

## 成稿补充要求

1. “可入口”“可啃咬”“无刺激”“新生儿适用”若未确认不得写死
2. 不得暗示治疗、促进发育、替代专业护理
3. 购买理由优先围绕“更安全、更省心、更好带娃”
4. 安全与舒适表达必须收敛，不能写成结果型承诺
5. 详情页必须同时兼顾“材质结构事实”和“家长使用体验”
6. 如果信息不足，宁可收敛表达，也不要硬写安心承诺
