## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是母婴用品特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 新生儿适用、全龄适用、孕妇可用
- 可入口、可啃咬、0刺激、0风险、绝对安全
- 促进发育、提升智力、改善睡眠、预防疾病、替代护理
- 医疗级、医院同款、专业级防护
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写“安心承诺”。

### 2. 补了母婴用品专用快路径

当用户已经给出：
- 产品名和品类
- 价格与规格
- 适用月龄或年龄段
- 至少 2 个卖点
- 材质/结构/使用方式中的至少 1 类信息
- 核心场景或竞品/价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合母婴用品的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 月龄和适用边界
- 材质、结构、安全依据
- 照护场景
- 清洁、消毒、收纳、携带便利性
- 家长为什么会拿某些竞品比较

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 喂养用品
- 洗护清洁
- 出行用品
- 安睡/护理/安全防护

这样可以减少“用同一套问题问所有母婴用品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`安全材质/结构 → 使用便利 → 清洁维护 → 照护场景 → 家长价值`

这比通用卖点结构更适合母婴用品，也更容易写出“真实、克制、让家长安心”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 亲子使用场景图
- 材质/结构细节图
- 安装或使用步骤图
- 尺寸与收纳图
- 清洁消毒示意图
- 外出携带场景图
- 月龄/使用方式说明图
