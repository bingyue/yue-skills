## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是 3C电器-小家电特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 杀菌、除螨、净化、消毒、医疗级效果
- 一级能效、超低噪音、实验室级静音
- 某个功率表现一定优于竞品
- 永久耐用、零耗损、完全免维护
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写实验室级性能承诺。

### 2. 补了 3C电器-小家电专用快路径

当用户已经给出：
- 产品名和品类
- 规格与价格
- 至少 2 个卖点
- 参数/模式/功能中的至少 1 类信息
- 家庭场景或目标人群
- 竞品或价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合电器类的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 参数和模式
- 功能点与家庭场景是否对应
- 清洁、维护、耗材和后续成本
- 噪音、体积、收纳、便携性
- 竞品、价格带与用户关注点

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 厨房小电
- 清洁电器
- 个护电器
- 环境电器
- 影音设备
- 办公电器

这样可以减少“用同一套问题问所有电器产品”的问题。

### 5. 补强了首轮响应模板

这次把开场回复也写成了可执行模板，分别覆盖：
- 信息不足时的补问模板
- 信息中等时的信息确认模板
- 信息较全时的大纲预览模板

这样可以减少首轮回复风格漂移，让 skill 更稳定地命中“先确认、再组织、再成稿”的节奏。

### 6. 补强了参数转译和长期成本表达

这次特别加强了 3C 行业里很关键、也最容易拉开质量差距的两块：
- 参数如何翻成用户能感知的收益
- 耗材、清洗、拆装、更换周期如何写得更像行业内行

现在会更明确地把：
- 功率/风量/吸力/马达
- 容量/续航/水箱/尘杯
- 滤网/刀头/滚刷/墨盒/电池

转成“节省哪一步、减少哪种麻烦、长期成本是否可控”。

### 7. 增加了风格与场景辅助规则

这次新增了一层对 3C 行业很重要的判断：

默认保持偏苹果风格的硬朗表达，优先讲参数、技术逻辑和效率收益；如果用户主动给出明确生活场景，比如：
- 母婴日常
- 宠物清洁
- 租房/小户型使用

就允许适度切换成“场景先行”的写法。

也就是说，现在 skill 不只是会写“参数是什么”，还会判断“这段文案是否需要增强代入感”，但不会把产品定义成只卖给某类人。

### 8. 增加了清洁电器、环境电器、厨房小电的场景模板

这次专门补了更细的高价值场景模板：
- 清洁电器：宠物家庭 / 母婴家庭 / 租房
- 环境电器：宠物家庭 / 母婴家庭 / 租房
- 厨房小电：母婴家庭 / 租房 / 单人

这些模板的作用，是把“场景代入感”变成可执行规则，而不是只停留在一句抽象建议。

### 9. 把厨房小电继续拆成 3 条业务线

这次继续往你行业里最容易拉开差距的地方深挖，把原来比较宽泛的“厨房小电”拆成：
- 咖啡饮品
- 空气炸/烹饪
- 辅食/热奶/养生

现在它会先判断属于哪条线，再决定追问什么、怎么组织卖点、怎么把参数翻成购买理由。

### 10. 补了厨房小电专属的参数转译

这次把厨房小电里最常见、也最关键的参数转译单独补出来了，比如：
- 咖啡饮品：萃取时间、水箱、豆仓、奶泡
- 空气炸/烹饪：容量、温控、预设菜单、可拆洗
- 辅食/热奶/养生：恒温、预约、保温、细腻度、单手操作

这样现在它不只是会说“参数更强”，而是能更自然地写成“早上出杯更快”“一顿饭更快落地”“夜间热奶更少打断”。

### 11. 增加了厨房小电首屏写法模板

这次不只是继续补问题池，而是把最影响真实文案表现的“首屏 opening”也写成模板了：
- 咖啡饮品：先写出杯节奏，再写门槛和清洗
- 空气炸/烹饪：先写做饭更容易坚持，再写一餐效率和收尾负担
- 辅食/热奶/养生：先写少打断和轻负担，再写参数支撑

这一步很关键，因为它会直接影响文案第一屏到底像不像真实商品页，而不只是像一个信息整理器。

### 12. 补了厨房小电的场景补充规则

这次还把 3 类高频使用场景单独拎出来了：
- 办公/桌面场景
- 夜间照看/高频加餐场景
- 轻负担饮食场景

这样它现在不仅能识别“这是什么产品”，还会继续判断“这类产品在什么使用情境下更容易让人代入”，再决定首屏应该先讲什么。

### 13. 重写了卖点结构

当前推荐顺序是：

`核心功能 → 使用效率 → 操作便利 → 家庭场景 → 后续维护成本`

这比通用卖点结构更适合 3C电器-小家电，也更容易写出“参数有意义、家庭能感知、后续好维护”的详情页。

### 14. 补强了竞品对比流程

这次把最容易出错、也最容易拉开商业价值差距的“竞品对比”补成了完整流程：
- 先锁定同价位
- 再锁定同类目、同用途
- 再决定是否需要多平台检索当前热销竞品
- 最后才进入配置、体验和维护成本对比

同时补了几条硬规则：
- “当前热销/热门/爆款”必须先检索或让用户给名单
- 不能跨类目乱比
- 不能在口径不一致时硬做量化

### 15. 增加了量化对比规则

这次也把“什么时候可以写量化优势”写清楚了。

现在只有在：
- 数据来源真实
- 对比口径一致
- 差异能被用户感知

这 3 个条件同时满足时，才允许写“容量更大多少”“机身更轻多少”“完成步骤更快多少”。

### 16. 增加了首屏标题/副标题结构

这次把首屏也继续补强了，不只是写 opening，而是明确了：
- 标题怎么把核心结果和同价位优势说清楚
- 副标题怎么补参数支撑和差异化落点

这样它现在更像成熟商品页的首屏结构，而不是只有卖点列表。

### 17. 做了一轮减法收口

这次没有继续加新能力，而是把几块容易变重的内容收轻了：
- 把“首轮响应策略 + 模板”合并成更短的“首轮最小决策”
- 把“竞品对比执行模板”压缩成更短的最小模板
- 把“对比板块”和“首屏结构”收成更像真实商品页会用的最小骨架

这一轮的目标不是加分炫技，而是把专业性藏回内核，让使用体验更轻。

### 18. 补了可落地的配图建议

当前优先建议：
- 家庭使用场景图
- 核心功能结构图
- 操作步骤图
- 容量/尺寸图
- 清洁维护图
- 配件/耗材说明图
- 场景前后对比图
