## 继承自母版的基础能力

这个品类默认继承了母版的通用能力：

1. 信息完整度判断
2. 快路径与补问路径切换
3. 信息确认检查点
4. 竞品与对比方向确认
5. 文案大纲预览
6. 成稿结构骨架
7. 输出前自检

这些通用能力的作用是保证不同品类都按同一条主流程运行，不会每个品类各写各的 workflow。

## 本品类专属优化

这次精修重点补的是家居日用特有的执行细节。

### 1. 强化了合规边界

重点约束了以下高风险表达：
- 零甲醛、绝对环保、医用级材质
- 绝对防霉、防水、防菌、抗菌、永久耐用
- 某个承重、容量、测试结果
- 所有空间都适用、所有家庭都适合
- 极限词和广告法高风险术语

同时补了降级写法，避免在信息不足时硬写性能承诺。

### 2. 补了家居日用专用快路径

当用户已经给出：
- 产品名和品类
- 规格与价格
- 至少 2 个卖点
- 材质/尺寸/结构中的至少 1 类信息
- 使用空间或核心场景
- 竞品或价格带

就允许直接进入“信息确认 + 大纲预览”，减少不必要追问。

### 3. 补了更贴合家居日用的首轮提问逻辑

和通用母版相比，这里首轮更关注：
- 材质和工艺
- 尺寸、容量、承重
- 安装、拆洗、收纳、维护方式
- 空间场景和适配关系
- 竞品、价格带与结构差异

### 4. 补了分品类问题池

当前已经按以下子类拆开了提问重点：
- 收纳用品
- 清洁工具/家清耗材
- 厨具餐具/卫浴用品
- 寝具家纺

这样可以减少“用同一套问题问所有家居产品”的问题。

### 5. 重写了卖点结构

当前推荐顺序是：

`材质/结构 → 使用便利 → 空间适配 → 清洁维护 → 长期价值`

这比通用卖点结构更适合家居日用，也更容易写出“具体、耐看、真有用”的详情页。

### 6. 补了可落地的配图建议

当前优先建议：
- 家居场景图
- 尺寸标注图
- 结构拆解图
- 使用步骤图
- 材质细节特写
- 清洁维护示意图
- 空间前后对比图
