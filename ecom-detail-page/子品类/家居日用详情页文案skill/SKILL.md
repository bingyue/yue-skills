# 家居日用详情页文案生成器

## 母版关系

当前 skill 是“全品类详情页文案母版”的家居日用子实现。

拆分方式如下：
1. 母版负责：通用主流程、信息完整度判断、检查点、成稿骨架、自检规则
2. 当前 skill 负责：家居问题池、尺寸与空间适配逻辑、材质结构表达、清洁维护写法、竞品维度

## 品类定位

这是一个围绕“材质结构 + 空间适配 + 使用便利 + 日常维护”来写详情页的子 skill，重点处理：
1. 材质与结构设计
2. 尺寸、容量、承重与空间关系
3. 使用步骤与操作便利性
4. 清洁维护与长期使用成本
5. 家居场景中的真实价值

## 适用品类

- 收纳用品
- 清洁工具
- 卫浴用品
- 厨具餐具
- 寝具家纺
- 家清耗材
- 居家小工具

## 不适用场景

- 需要专业安装和施工认证的工程类家装产品
- 家具大件定制方案页
- 用户明确要短视频脚本、种草帖、直播口播，而不是详情页

## 品类核心原则

1. 先讲材质和结构，再讲使用便利，再讲空间和生活价值
2. 尺寸必须跟场景一起写，不能只堆数字
3. 承重、容量、防水、防霉等能力必须有依据
4. 家居类文案要减少悬浮形容词，多写真实生活改善点
5. 配图建议必须能支持用户理解尺寸、结构和使用方式

## 家居日用专用快路径

如果用户已经给出以下信息中的大部分，可直接进入“信息确认 + 大纲预览”：
1. 产品名和品类
2. 规格与价格
3. 至少 2 个明确卖点
4. 材质/尺寸/结构中的至少 1 类明确信息
5. 目标使用空间或核心场景
6. 竞品或价格带

不要命中快路径的情况：
- 只说“很实用”“很高级”“很省空间”
- 没有尺寸、材质、结构依据
- 产品是否适配某个空间仍完全不明确

## 首轮响应策略

### 模式A：信息不足

优先问这 5 个问题：
1. 产品名称、具体品类和规格是什么？
2. 售价或价格带是多少？
3. 这款产品最想打的 3 个卖点是什么？
4. 材质、结构、尺寸、容量或承重上有什么明确亮点？
5. 主要用于什么空间或生活场景？厨房、卧室、客厅、卫生间、玄关还是阳台？

### 模式B：信息中等

如果用户已提供部分信息，优先补这几类缺口：
1. 材质和工艺是否明确
2. 尺寸、容量、承重是否明确
3. 安装、拆洗、收纳、维护方式
4. 核心空间场景和适配关系
5. 竞品、价格带与结构差异

### 模式C：信息较全

直接进入：
1. 产品信息汇总
2. 尺寸与使用场景适配确认
3. 文案大纲预览

## 家居日用信息池

### 基础信息
1. 产品名称
2. 细分品类
3. 规格
4. 价格
5. 品牌定位

### 材质与结构
6. 核心材质是什么？
7. 是否有工艺、层数、分区、折叠、挂装、抽拉等结构亮点？
8. 是否有耐水、防潮、防锈、抗污、易清洁等信息？

### 尺寸与适配
9. 尺寸、容量、承重、数量、层数是多少？
10. 更适合什么空间？厨房、卧室、客厅、卫生间、玄关、桌面、橱柜内部？
11. 是否适合小户型、租房、家庭收纳、儿童房、宿舍等特定场景？

### 使用与维护
12. 安装方式复杂吗？
13. 是否可拆洗、可折叠、易收纳？
14. 日常使用痛点解决在哪？节省空间、减少翻找、方便打理、动线更顺？

### 竞品与依据
15. 主要竞品是谁？
16. 用户为什么会拿这些竞品比较？
17. 防水、防霉、环保、承重等信息是否有依据？

## 分品类问题池

### 收纳用品
- 是桌面收纳、橱柜分层、衣柜整理、浴室置物还是玄关收纳？
- 尺寸、层数、分区、抽拉方式是否明确？
- 更适合小空间、租房、儿童房还是高频家庭整理？
- 是否需要安装？是否容易拆装和清洁？

### 清洁工具/家清耗材
- 主打去污、除味、便捷、省时还是多场景使用？
- 是一次性耗材还是重复使用？
- 使用步骤、适用材质、清洁范围是否明确？
- 是否容易补充、更换、收纳？

### 厨具餐具/卫浴用品
- 材质、耐热、容量、防滑、防漏等信息是否明确？
- 更适合家庭日常、租房、露营、多人聚餐还是单人使用？
- 是提升操作效率还是减少清洁负担？

### 寝具家纺
- 主打亲肤、柔软、透气、保暖还是易打理？
- 尺寸、面料、清洗方式是否明确？
- 更适合四季通用、换季、儿童房还是宿舍场景？

## 合规边界

### 禁止直接写死的内容

以下内容没有明确依据时，不能写成确定事实：
- 零甲醛、绝对环保、医用级材质
- 绝对防霉、防水、防菌、抗菌、永久耐用
- 某个承重、容量、测试结果
- 所有空间都适用、所有家庭都适合
- 一劳永逸、彻底解决收纳问题

### 允许的降级写法

- “更偏向小空间整理场景”
- “如果用户更在意易清洁，这个卖点可以优先展开”
- “基于已知信息，优势主要集中在结构设计与收纳便利性”
- “更适合厨房台面或卫浴角落这类高频使用区域”

### 广告法与极限词约束

1. 不使用“第一、唯一、顶级、极致、完美、永久、100%”等极限词
2. 不使用“绝对防霉、永久耐用、全网最好收纳、零甲醛”这类无法举证的广告法高风险表述
3. 不把结构、材质、耐用性写成保证性承诺，如“永不变形、绝不发霉、完全防水”
4. 用户原话若带极限词，输出时必须主动降级改写

## 竞品对比维度

必须从以下维度中选择适用品类项：
- 材质
- 尺寸/容量/承重
- 结构设计
- 清洁维护
- 空间适配
- 使用便利
- 价格

对比原则：
1. 优先比结构逻辑和场景适配差异
2. 少写“比竞品更高级”这类空泛结论
3. 若无明确测试，不写绝对耐用或绝对环保
4. 对比结论尽量落到“更适合什么空间、什么家庭”

## 卖点结构

优先使用以下 5 类卖点模块：
1. 材质亮点
2. 结构设计
3. 使用便利
4. 空间适配
5. 清洁与长期使用价值

推荐顺序：
`材质/结构 → 使用便利 → 空间适配 → 清洁维护 → 长期价值`

### 卖点示例写法

- `分层更清楚。常用物品能更快拿取，台面也不容易显乱。`
- `抽拉设计。放进橱柜内部后，深处物品也更容易拿到。`
- `可拆洗结构。高频使用后更方便打理，也更适合厨房或卫浴场景。`

## 风格要求

适合“生活感、秩序感、实用感、轻改造感”，少喊口号，多写解决问题。

避免：
- 收纳界第一名
- 全屋必备神器
- 永久耐用
- 一秒治好家里乱

推荐：
- 更适合高频使用区域整理
- 把常用物品归位后，台面会更清爽
- 安装和清洁步骤更简单，日常维护更省事
- 对小空间家庭更友好

## 配图建议

每个卖点至少给一种可落地配图方向。

优先给出：
- 家居场景图
- 尺寸标注图
- 结构拆解图
- 使用步骤图
- 材质细节特写
- 清洁维护示意图
- 空间前后对比图

## 成稿补充要求

1. 未确认的环保、抗菌、防霉、防水等级不得写死
2. 尺寸与适配场景要对应，不可空泛
3. 购买理由优先写“省空间、好打理、易使用、耐久”
4. 详情页必须同时兼顾“结构事实”和“生活场景”
5. 如果信息不足，宁可收敛表达，也不要硬写性能承诺

- [ ] 是否明确了尺寸和空间适配关系

- [ ] 是否给出了真实的生活场景
- [ ] 是否给出了能拍出来的配图建议
- [ ] 是否存在极限词或广告法高风险术语
