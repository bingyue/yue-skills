# 电商详情页文案 Skills

这是一个面向电商详情页文案生成的 skill 体系库，包含通用母版、全品类子 skill，以及深度定制的爆款品类 skill。

这套仓库的目标不是简单生成几句商品文案，而是让 AI 能按真实电商运营流程逐层理解产品、提炼卖点、处理竞品对比，并最终输出更能落地的详情页文案。

## 使用方式

### 方式一：整仓使用

适合需要完整详情页文案体系的团队或个人。

你可以 clone 整个仓库，然后按 `母版 -> 子品类 -> 深度定制` 的顺序理解和使用。

### 方式二：单独使用某个 skill

每个 skill 文件夹都可以独立取用。

如果你只需要某一个品类，例如 `服饰鞋包详情页文案skill`，只需要复制这个文件夹到你的 skills 目录即可，不需要安装整个仓库。

## 分类说明

### 母版

`文案母版skill` 是通用详情页文案流程母版，负责沉淀通用工作流：

- 信息完整度判断
- 前置调研
- 卖点提炼
- 竞品对比
- 成稿结构
- 合规约束

### 子品类

`子品类` 放通用品类详情页文案 skill。

这些 skill 更适合大众电商商品页，强调稳定、清晰、可复用。

当前包含：

- 美妆个护
- 家居日用
- 食品饮料
- 母婴用品
- 服饰鞋包
- 宠物用品
- 运动户外
- 3C电器/小家电
- 珠宝饰品

### 深度定制

`深度定制` 放长期深打、强行业属性、强爆款属性的专属 skill。

当前包含：

- 洗地机爆款详情页文案skill

这类 skill 不追求轻量，而是允许更高信息密度、更强竞品压制、更完整的爆款详情页结构。

## 统一规范

每个成熟 skill 目录建议包含：

- `SKILL.md`：核心执行规则
- `README.md`：预览说明
- `test-prompts.json`：测试样例
- `results.tsv`：评分记录

所有详情页文案 skill 默认需要遵守：

- 不编造参数
- 不虚构认证
- 不硬写未经确认的竞品结论
- 避免广告法极限词和高风险表达
- 竞品对比必须确认可比口径

## 深度定制的特殊规则

深度定制类 skill 可以比通用品类更重、更密、更强势。

以 `洗地机爆款详情页文案skill` 为例，它已经沉淀出：

- 先调研，再出稿
- 问卷按 `核心必填 / 证明项 / 后置加分项` 分层
- 竞品压制前必须锁定 `1 个直接对标型号`
- 对标素材优先级为 `截图文件夹 / 单页截图 / 商品链接`
- 超级爆款页允许核心差异卖点多次复现
- 长详情页可以高密度展开，但每个大词必须有证据托底

## 推荐维护方式

- 新增通用品类时，放入 `子品类/`
- 新增行业深打版本时，放入 `深度定制/`
- 每次精修后同步更新该目录的 `README.md`
- 每次评分后同步追加 `results.tsv`
- 如果某个深度定制 skill 后续变成公共通用品类，可以再抽象回子品类
