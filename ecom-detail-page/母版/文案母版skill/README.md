# 文案母版skill

这是一个“全品类详情页文案母版”，作用不是直接服务某个单一品类，而是沉淀一套可以复用的详情页 workflow。

## 这份母版解决什么问题

- 把“信息采集 → 信息确认 → 竞品筛选 → 大纲预览 → 完整成稿 → 自检”做成稳定骨架
- 让不同品类只需要替换自己的参数、卖点结构、竞品维度和风格层
- 避免以后每扩一个品类，都从头重新写一份 skill

## 推荐扩展方式

1. 保留本目录作为标本，不直接混入某个单独品类的专业细节
2. 新建子 skill 时，优先复制本母版，再补充对应品类的：
   - 关键问题池
   - 竞品对比维度
   - 卖点结构模板
   - 风格偏好
3. 每个子 skill 完成后，再单独做评分和优化
