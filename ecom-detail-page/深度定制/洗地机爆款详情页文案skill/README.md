## 基础定位

这不是“全行业通用详情页模板”，而是一个故意做复杂、做顶配、做高密度的标杆版。

目标很明确：
- 完全参考头部爆款详情页的表达逻辑
- 允许大词、允许强气势、允许信息密度高
- 不做压缩，不先做减法
- 先把“最复杂、最顶配的车”造出来

后面其他品类如果要扩，就可以照着它做减法。

## 这版最重要的 5 个核心观念

### 1. 先立顶层价值

洗地机首屏不能只写功能和参数，必须先定义：
- 这台机器最值得买的那件事是什么
- 它到底在重新定义什么标准

### 2. 先讲结果，再讲证明

不是先讲“我有什么功能”，而是先讲：
- 洗得净
- 不缠毛
- 不返臭
- 更省力
- 大户型更好洗

然后再用参数、技术、测试和认证去证明。

### 3. 每个模块默认按“问题 → 方案 → 证明”推进

这版 skill 明确要求洗地机卖点模块都按这个顺序展开，不允许只罗列配置。

### 4. 竞品对比要主动重写比较标准

不是跟着竞品卷“吸力”这种单点指标，而是要主动把用户判断标准改成：
- 洗净能力
- 防缠毛链路
- 净味效果
- 助力体验
- 大户型完成度

### 5. 高密度可以，但不能乱

这版允许信息多、节奏强、气势大，但前提是：
- 每一层都有逻辑
- 每一个大词后面都有证明
- 不是“很强很满很累”的空洞堆叠

### 6. 新增了检查点机制

这次补了 3 个很关键的控制点：
- 顶层价值确认
- 结构预览确认
- 对比与量化确认

这样它虽然是高密度版本，但不会一路写满才发现方向偏了。

### 7. 新增了对比板块成稿模板

这次把“竞品对比”继续往前推了一步，不只是告诉它怎么判断，还告诉它：
- 对比模块标题怎么起
- 引导语怎么写
- 差异表保留哪些字段
- 总结语怎么把优势落回真实动作和场景

这能让它更像成熟商品页团队在做模块，而不是只会输出原则。

### 8. 强化了高密度版最小输出要求

现在即便走高密度路线，也必须守住 5 个底线：
- 先有顶层价值
- 再有结果总览
- 模块都按问题/方案/证明推进
- 对比模块能独立成立
- 收尾能回扣总价值

### 9. 新增了两套成稿骨架样例

这次直接补了两套更接近真实落地的高密度成稿骨架：
- `全能旗舰型`
- `超薄大吸力/强差异型`

作用不是提供固定文案，而是让 skill 在真实运行时更容易写出“像头部爆款详情页”的结构和气势。

这一步很重要，因为它把 skill 从“会搭规则”继续推进到了“更会落地成稿”。

### 10. 新增了默认调研开场流程

这次把“先调研、再成稿”正式写成默认动作，不再是临时建议。

新增内容包括：
- 开场安抚话术
- 调研进度同步话术
- 调研结果利弊说明
- 分层问卷结构：`核心必填 / 证明项 / 后置加分项`

这样用户在刚开始做详情页时，不会一上来就被长问卷压住，也更容易理解为什么先做配置调研能提升最终文案质量。

同时这里继续沿用了现在的总方向：
- 不把产品过早写窄成人群定制款
- 优先围绕 `核心配置 + 关键配置 + 基础竞品信息` 先推进
- 在保证大众商品表达的前提下，提升代入感和准确度

### 11. 问卷进一步做减法

这轮继续按真实实测体验做了减法，把一批“首轮不直接决定出稿”的字段移出了默认必填。

现在默认逻辑更清楚了：
- `核心必填` 只问会直接决定首屏和结构的内容
- `证明项` 只保留会直接进入参数证明和竞品对比的内容
- `后置加分项` 放到结构确认后再补

而且这轮又按你的实际使用习惯做了细节调整：
- `核心方向` 改成 `核心配置`
- 去掉 `热水洗/温度`
- 去掉 `竞品价格区间`
- 新增独立字段 `卖点补充`

这样客户在第一轮填写时会明显更轻，也更能感受到“每个问题后面都会直接变成文案的一部分”。

### 12. 新增了超级爆款页展开规则

这轮还补了一条很关键的规则：
`超级爆款页允许核心差异卖点多次复现，并分多屏高密度展开。`

这更接近头部洗地机详情页的真实打法。

不是一条卖点讲一遍就结束，而是把最强差异：
- 放在首屏立一次
- 在功能模块里拆一次
- 在竞品对比里再压一次
- 在收尾里再回扣一次

这样页面长度、密度和卖点压制力才会更像真正的爆款详情页。

### 13. 新增了直接对标型号硬门槛

这轮把竞品对比继续收紧了一步：
如果想把对比模块写到“具体压制”的程度，就必须先锁 `1 个直接对标型号`。

素材优先级也定死了：
- `截图文件夹`
- `单页截图`
- `商品链接`

这样做的原因很现实：
- 电商平台链接经常读不全
- 截图文件夹最适合逐屏拆标题、节奏、功能展开和对比逻辑
- 只锁 1 个型号，对比模块会更聚焦，不会写散

现在没有直接对标型号时，skill 会默认降级成：
- 只写对比方向
- 只写对比框架
- 不把具体压制写死

## 适用场景

- 洗地机爆款详情页

- 想先造“标杆版骨架”，再给其他品类做减法
