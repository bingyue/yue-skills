# 电商数据看板

## 核心指标

| 指标 | 说明 |
|---|---|
| GMV / 净销售额 | 总成交额与实收金额 |
| 转化率 | UV 转化、点击转化 |
| 客单价 | 平均订单金额 |
| 复购率 | 30/60/90 天回购用户占比 |
| ROI | 广告/活动投入产出比 |
| 退款率 | 退款订单占比及原因分布 |

## 工作流

1. **数据接入**：粘贴数据或上传 CSV（必需列：日期, 销售额, 订单数, 访客数）
2. **指标计算**：自动推导所有派生指标
3. **趋势分析**：环比/同比变化，标记异常波动
4. **看板渲染**：输出 HTML 交互看板 或 Markdown 表格报告
5. **预警说明**：标注需要关注的异常指标

