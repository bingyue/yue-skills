# CSV 智能报告生成

## 自动识别能力

- **数据类型**：时间序列 / 分类统计 / 财务明细 / 用户行为 / 调研问卷
- **统计量**：均值/中位数/标准差/最大最小值/异常值检测
- **关联分析**：识别强相关列对，提示因果关系
- **趋势识别**：自动发现增长/下滑/周期性规律

## 工作流

1. 粘贴 CSV 数据或描述数据结构
2. Agent 识别数据类型和关键列
3. 计算核心统计指标
4. 生成叙述性洞察（3-5 条核心发现）
5. 推荐最适合的图表类型和绘制提示词

## 触发关键词

"分析这份数据" / "CSV 报告" / "数据洞察" / "帮我看看这个表格"

## 输出结构

```
# 数据报告：[文件名]

## 数据概览
- 行数/列数 / 时间范围 / 数据质量

## 核心发现
1. [发现1] ...
2. [发现2] ...

## 关键指标摘要（表格）

## 图表建议
- 推荐图表类型 + Mermaid/ECharts 绘制代码
```
