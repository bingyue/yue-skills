# 电商评论舆情监控

## 功能概览

- **差评预警**：自动识别差评关键词，按问题类型分类（物流/质量/描述不符/售后）
- **竞品挖掘**：扫描竞品高频差评，提炼可利用的产品改进点
- **情感分析**：三层结构（ABSA 维度打分 + 痛点提炼 + 推荐指数）
- **周报输出**：生成 Markdown 格式评论周报，含趋势图表描述

## 工作流

1. **数据输入**：粘贴评论文本 / CSV / 产品链接
2. **问题分类**：按维度（功能/外观/物流/服务/性价比）打标签
3. **竞品对比**：输入竞品 ASIN 或链接，对比差评分布差异
4. **报告生成**：输出结构化分析报告

## 触发场景

- "帮我分析这个产品的差评"
- "看看竞品用户在抱怨什么"
- "生成评论舆情周报"
- "找出用户最常提到的问题"

## 输出格式

```
# 评论舆情报告 - [产品名] - [日期]

## 核心指标
- 总评论数 / 差评率 / 平均分

## TOP 5 问题维度（按频次）
1. [维度] [频次] [代表性评论]

## 用户痛点词云（高频词）

## 竞品差评对比

## 改善建议（优先级排序）
```
